# E07 実装指示文：すなばくに ねむる たからもの

## 0. 実装の目的と基本方針

5歳の女の子が、黄金色の砂漠に埋もれた巨大な古代モザイクを、真鍮製の送風機を使って発掘する、写実的な3Dウェブゲームを制作してください。

このゲームの主役は、砂漠でも送風機でもなく、**自分の指で大量の砂を吹き飛ばすことで、地中から美しい色石細工が次々と現れる体験**です。

単なる宝石探しや、画面をこすって画像を表示させるゲームにはしないでください。砂の厚み、風の勢い、砂粒の飛散、石の表面への光の反射を立体的に表現し、本当に砂漠で発掘作業をしているような感覚を作ってください。

文字による説明は一切不要です。5歳児が画面を見ただけで遊び方を理解でき、保護者の介助なしで最後まで楽しめることを最優先してください。

## 1. ゲームの狙い

- **夢×写実：** 黄金色の砂丘、壮大な積雲、精密な砂の風紋、ラピスラズリや翡翠の質感を写実的に描き、現実の砂漠に夢のような巨大工芸品が眠っている世界を作る。
- **高揚感：** 小さな色石の発見から、複雑な幾何学模様の出現、巨大な太陽の意匠の完成へと、発見の規模が段階的に大きくなる喜びを作る。
- **爽快感：** 指を少し動かすだけで大量の砂が勢いよく吹き飛び、隠れていた美しい石の表面が一気に現れる、掃除や砂遊びに通じる快感を作る。

特に、「砂で覆われている状態」と「発掘後の鮮やかな状態」の視覚的な差を大きくしてください。

## 2. 絵から借りる光と色

### 2.1 美術の方向性

メイナード・ディクソンの提示された参考画から、赤褐色の大地、澄んだ青空、巨大な白い積雲、広大な空間がもたらす開放感を借りてください。

参考画の構図や筆致を再現するのではなく、実際の砂漠を高品質なカメラで撮影したような写実3Dの世界として再構築してください。

そこに、現実には存在しないほど美しい古代の色石細工、光を受けて輝く鉱物、砂漠全体へ広がる魔法のような光の演出を組み合わせてください。

児童向けファンタジー映画に通じる驚きと祝祭感を持たせつつ、既存のキャラクター、建築物、作品固有の意匠、ブランド要素は一切使用しないでください。

### 2.3 時間帯とライティング

ゲームの進行に合わせ、昼下がりから黄金色の夕刻へと、数分かけて連続的に変化させてください。夜には移行させません。

|---|---|---|---|

| 太陽光の色温度 | 約5800K | 約5000K | 約4200K |

| DirectionalLight強度 | 3.0 | 3.2 | 3.5 |
| HemisphereLight強度 | 1.5 | 1.6 | 1.7 |
| 環境反射強度 | 0.8 | 1.0 | 1.2 |
| ブルーム強度 | 0.25 | 0.45 | 最大1.1 |

数値は使用するThree.jsのバージョンと実際の描画結果に応じて調整して構いません。

- トーンマッピング：ACESFilmicToneMapping。
- 露出：0.95〜1.10程度。
- 出力色空間：sRGB。

クライマックスでも露出を急激に増加させないでください。発光範囲、反射の移動、光の粒子、模様の変化によって壮大さを表現します。

## 3. 舞台と登場するもの

### 3.1 砂漠の地形

発掘現場を中心に、半径400〜600m程度の砂漠をプロシージャル生成してください。1 Three.js unitを概ね1mとして扱います。

- 発掘現場の周囲には、なだらかな黄金色の砂丘を配置する。
- 遠景には、高さ30〜90m程度の赤褐色の岩山を配置する。
- 岩山には堆積岩特有の水平な地層、浸食された谷、風化した角を作る。
- 地形の高さは複数のノイズと緩やかな波形を合成して生成する。
- 地面の法線に細かな風紋を追加し、斜めからの太陽光によって凹凸が浮かび上がるようにする。

砂のマテリアルは、roughness 0.85〜0.98、metalness 0.0を基本とします。

砂粒を地面全体に個別の球体として配置する必要はありません。プロシージャルな色の変化、法線マップ、近景の微細な粒子を組み合わせて質感を表現してください。

### 3.2 空と巨大な積雲

青空には、参考画のような巨大な白い積雲を配置してください。

雲は平面的な円形の集合に見せず、上部の白い雲塊、下部の青灰色の陰影、内部の奥行きを表現してください。

高負荷なリアルタイム体積レンダリングは必須としません。3Dノイズから生成した雲のメッシュや、手続き的に生成した透過テクスチャを使い、少ない描画負荷で積雲の立体感を再現してください。

雲は毎秒0.2〜0.5m程度の速度で、ゆっくり移動させます。積雲のスケールは遠景の岩山よりもはるかに大きくし、空の壮大さを演出してください。

### 3.3 巨大な円形モザイク

発掘する工芸品は、直径約14mの巨大な円形モザイクとします。

石材を切り出して組み合わせた古代の精巧な工芸品として、次の構造を作ってください。

| 部位 | 意匠・素材 |
|---|---|
| 中央円盤 | 黄金色の太陽、乳白色の石、放射状の光線模様 |
| 内周 | ラピスラズリと金細工による花弁状の模様 |
| 中周 | 翡翠とトルコ石による連続した幾何学模様 |
| 外周 | 瑪瑙、乳白色の石、金色の縁取り |
| 最外縁 | 厚みのある風化した砂岩の円形枠 |

模様は極座標を利用してプロシージャル生成し、放射対称性を持たせてください。実在する宗教施設や遺跡の意匠をそのまま複製しないでください。

モザイクを単一の平面テクスチャにせず、石片に0.02〜0.06m程度の厚みを持たせます。石片の間には目地を作り、面取り、細かな傷、わずかな高さの違いを加えてください。

石片の数はhighで1500〜2500個程度を目安とし、InstancedMeshや結合ジオメトリを使用してください。

### 3.4 色石と金属のマテリアル

| 素材 | Roughness | Metalness | 特徴 |
|---|---:|---:|---|
| ラピスラズリ | 0.25〜0.40 | 0.0 | 青色の濃淡と微細な金色の斑点 |
| 翡翠 | 0.18〜0.32 | 0.0 | 石の内部に光が入るような色の変化 |
| トルコ石 | 0.30〜0.45 | 0.0 | 細かな鉱物の模様 |
| 瑪瑙 | 0.22〜0.35 | 0.0 | 層状の色の変化 |
| 真珠母貝 | 0.18〜0.30 | 0.0 | 視線角度で変化する虹色の反射 |
| 金細工 | 0.20〜0.30 | 0.9〜1.0 | 鮮明な金属反射 |
| 真鍮 | 0.28〜0.42 | 0.8〜1.0 | 使用感のある金属表面 |

環境マップはプロシージャルな空と太陽から生成してください。可能であればPMREMを使用します。

色石は常時発光させず、通常時は鉱物としての質感を重視してください。魔法の光は、発掘成功時とクライマックスに限定します。

### 3.5 真鍮製の送風機

送風機は、小型の古い工芸機械を思わせる形状とします。

構成要素は以下のとおりです。

- 円筒形の真鍮製本体。
- 内部に回転する羽根が見える吸気口。
- 先端に向かって細くなる送風ノズル。
- 銅色の接合部、ボルト、装飾的な金属リング。
- 木製の持ち手。
- 稼働中に回転速度が増すファン。

全長は0.9〜1.2m程度。モザイクの近くに浮かぶ、指で直接扱える道具として配置します。

操作中はノズルの方向が砂に向き、送風機の本体がわずかに振動するようにしてください。人物や手の3Dモデルは不要です。

本作には乗りもの、動物、水場を追加しません。砂漠の発掘体験に集中させ、水面反射に相当する視覚的な魅力は、研磨された色石と金属の環境反射で表現してください。

## 4. 指1本のゲームループ

### 4.1 開始画面

最初から3Dの砂漠と、砂に埋もれた円形モザイクを表示してください。

モザイクの大部分は砂に覆われていますが、一部分だけ青い色石が露出しています。その近くには真鍮製の送風機があります。

送風機の金属リングに光が流れ、内部のファンが一瞬だけ回転し、ノズルの先にある砂が少し舞い上がります。この演出によって、送風機と砂の関係を自然に伝えてください。

送風機または発掘範囲に触れると、そのままゲームが始まります。開始専用のメニュー画面は設けません。

### 4.2 1回の発掘の流れ

| 経過時間の目安 | 子どもの操作・画面の反応 |
|---|---|
| 0秒 | 砂の隙間から色石が光り、発掘できる場所が分かる |
| 0〜1秒 | 指で送風機に触れる、または砂に直接触れる |
| 1〜2秒 | 送風機が指の位置へ移動し、ファンが回転する |
| 2〜4秒 | 指を動かすと、砂が扇状に勢いよく吹き飛ぶ |
| 4〜6秒 | 砂の下から鮮やかな色石細工が連続して現れる |
| 6〜7秒 | 発掘部分に光が走り、石と金属が響く成功音が鳴る |
| 7〜8秒 | 次の発掘範囲にある砂がわずかに動き、色石が光る |

このループを繰り返し、巨大なモザイクを完成させます。

秒数は標準的な遊び方の目安であり、操作の速い子どもを待たせるための制限時間にはしないでください。

### 4.3 送風機の操作感

指が砂に触れている間は、自動的に送風してください。細かい操作技術や、特定の形をなぞることは要求しません。

- 指の位置に送風機が追従する。
- 追従時の補間時間は0.08〜0.15秒程度。
- 指を止めても送風を継続する。
- 指を速く動かすと、一度に広い範囲の砂が吹き飛ぶ。
- 指を離すと、0.2〜0.4秒かけて送風が止まる。
- 送風中はノズルの先から砂が遠ざかる方向へ飛散する。
- 発掘済みの場所を再度吹いても、残った微細な砂粒が舞い上がる。

送風範囲は見た目のノズルより広くし、幅1.0〜1.8m程度の扇状とします。

短いタップでも一定量の砂が取り除かれるようにしてください。長押しやドラッグだけを必須操作にしないこと。

### 4.4 砂の除去と飛散表現

砂を単に透明化して消すのではなく、厚みのある砂が風によって移動し、地中の石材が露出するように見せてください。

モザイク上の砂の分布は、極座標グリッドまたは512×512程度の動的マスクで管理します。

送風範囲内の砂の厚みを連続的に減らし、その減少量に比例して飛散粒子を生成してください。

粒子には少なくとも以下の3種類を用意します。

| 粒子 | 挙動 |
|---|---|
| 細かな砂粒 | 風に乗って速く移動する |
| やや大きな砂粒 | 放物線を描き、地面に落下する |
| 砂煙 | 広がりながら徐々に消散する |

砂粒の初速は4〜12m/s、寿命は0.4〜1.2秒程度とします。

細砂が勢いよく飛び、重い粒は少し遅れて落ちることで、物理的な説得力を出してください。砂煙の透明度は最大0.2程度とし、発掘対象が見えなくなるほど濃くしないでください。

除去した砂は元の場所に戻さず、モザイクの外側にわずかに堆積するように表現します。

完全な流体・粉体シミュレーションは不要です。軽量な近似モデルを使用し、描画の滑らかさを優先してください。

### 4.5 成功判定

モザイクは全28区画に分割します。区画の境界線はゲーム用のUIとして表示しません。

各区画の砂が約80〜85%取り除かれた時点で発掘成功とし、残りの砂を0.4〜0.7秒の追加送風演出で完全に取り除いてください。

最後のわずかな砂を探して画面を細かくこする必要がないようにします。

成功した区画では、以下の反応を同時に発生させてください。

- 砂が最後に勢いよく吹き飛ぶ。
- 石材の表面に太陽光の反射が走る。
- 模様の輪郭を金色の光が一周する。
- 短い成功音が鳴る。
- 少量の金色の光粒子が空中へ舞う。

発掘した区画は永久に露出した状態を維持します。ただし新しい周回を開始するときは、発掘状態をリセットします。

### 4.6 失敗のない設計と誘導

間違った場所に触れても失敗にしないでください。制限時間、減点、警告音、燃料切れ、道具の破損は実装しません。

発掘順序も強制しません。子どもが先の段階の範囲に触れた場合も砂を除去し、その成果を保存してください。

操作が止まった場合は、次の演出で自然に誘導します。

- 2.5秒：未発掘部分の隙間から色石の反射が見える。
- 4秒：その周辺の砂が風でわずかに動く。
- 6秒：送風機が未発掘部分の方向を向き、ファンが一瞬回転する。
- 以降：一定間隔で誘導を繰り返す。

誘導演出だけで区画が勝手に完成することはありません。

文字、矢印、手のアイコン、点滅するUIボタンは使用しないでください。

## 5. 盛り上がりの設計

全体を4段階、各7区画の発掘で構成します。通常の遊び方で約3〜5分を目安とします。

発掘範囲はモザイクの中心を基準とした同心円状に配置し、どの段階でも発掘対象全体の中心が画面中央にあるようにします。

### 第1段階：あおい たからもの

開始時は、中心付近のラピスラズリの一部だけが見えています。

中央円盤の外側にある内周部分から7区画の発掘を促します。

砂を取り除くと、青い石と細い金細工による花弁状の意匠が現れます。7区画が揃うと、花弁をつなぐ金色の反射が一周します。

- 発掘時の送風範囲：約1.0m。
- 砂粒の量：基準値。
- 成功音：単音と短い倍音。
- カメラ：モザイクの中央部分を比較的大きく表示する。

### 第2段階：みどりの かざり

翡翠とトルコ石が使われた中周部分を7区画発掘します。

1区画ずつ露出するたびに、青と緑の石が組み合わさった精巧な幾何学模様が広がっていきます。

7区画が揃うと、内周と中周の模様が光でつながります。

- 発掘時の送風範囲：約1.3m。
- 砂粒の量：基準値の1.25倍。
- 成功音：2音の和音。
- カメラ：第1段階より約15%視野を広げる。

### 第3段階：おおきな まる

外周部分の7区画を発掘します。

赤橙色の瑪瑙、乳白色の石、金色の装飾が現れ、工芸品全体の巨大さと色彩の豊かさが判明します。

外周の発掘が完了すると、円形モザイクの外縁に沿って金色の光が一周し、中央にまだ砂が残っていることが分かります。

- 発掘時の送風範囲：約1.6m。
- 砂粒の量：基準値の1.5倍。
- 成功音：3音の和音と金属の余韻。
- カメラ：巨大な円盤全体と、その周囲の砂漠を表示する。

### 第4段階：たいようの たからもの

最後に中央円盤の7区画を発掘します。中央円盤はモザイク全体の直径の30%程度を目安とし、太陽の意匠を十分な大きさで表現してください。

砂の下から黄金の太陽と乳白色の放射模様が現れます。

最後の区画では送風の勢いを増し、残っていた砂が円盤の外側へ一斉に吹き飛ぶようにしてください。

- 発掘時の送風範囲：約1.8m。
- 砂粒の量：基準値の1.8倍。
- 成功音：広がりのある和音と長い余韻。
- カメラ：中央円盤とモザイク全体を収める。

先の段階を既に発掘している場合は、その成果を引き継ぎます。発掘済みの部分を再び砂で覆ったり、同じ作業を強要したりしないでください。

### 5.1 クライマックス：砂漠に現れた太陽

全28区画の発掘が完了すると、約12秒間のクライマックス演出を開始します。

| 時間 | 演出 |
|---|---|
| 0〜2秒 | 中央円盤の周囲に残った微細な砂粒が吹き飛ぶ |
| 2〜5秒 | 中央円盤が約0.15mせり上がり、ゆっくり回転する |
| 5〜7秒 | 中央の太陽の意匠が太陽光を反射し、黄金色に輝く |
| 7〜9秒 | 光が内周、中周、外周へ順番に伝わる |
| 9〜10秒 | 円形モザイク全体が鮮やかに輝き、金色の光粒子が舞う |
| 10〜12秒 | 光が徐々に落ち着き、完成した美しい工芸品が残る |

中央円盤の回転速度は毎秒15〜25°程度とします。円盤の回転によって石材の反射が移動することを重視してください。

光の波はモザイクの幾何学模様に沿って伝播させます。爆発や画面全体のフラッシュではなく、工芸品に蓄えられた光が解放されるような表現にしてください。

ブルーム強度は最大でも1.2程度、しきい値は0.8以上とします。光が最大になる瞬間にも、太陽の意匠、各色石、モザイクの輪郭、背景の青空が識別できることを必須とします。

### 5.2 余韻と再プレイ

クライマックスの後は、完成したモザイクをゆっくり眺められる時間を設けます。

送風機を操作すると、石材の上に残った微細な砂粒を吹き飛ばしたり、光粒子を舞い上がらせたりできるフリープレイ状態へ移行してください。

10秒以上経過して操作が止まった場合には、砂漠の風が少しずつ砂を運び、8〜12秒程度かけてモザイクを再び覆います。

最初の色石が顔を出した状態に戻り、新しい発掘を開始できるようにしてください。突然の画面暗転や強制的なメニュー遷移は行いません。

## 6. カメラ設計

カメラは、円形モザイクの中心を常に注視する固定軸方式を基本としてください。

水平面から約50〜65°の俯瞰角度とし、モザイクの模様、石材の厚み、砂の飛散、遠景の岩山と積雲を同時に楽しめる構図にします。

開始時からモザイクの外縁が画面内に収まるようにし、内周の色石細工を視認できる距離を確保します。発掘が進むにつれて少しずつカメラを引き、砂漠の壮大さを増してください。

- PerspectiveCameraの垂直FOV：38〜48°程度。
- モザイクの投影範囲：画面の短辺の65〜82%以内。
- 画面端の安全余白：各辺8%以上。
- カメラ移動の補間時間：1.5〜3秒程度。
- カメラのロール：常に0°。
- カメラの振動、急旋回、急激なズームは禁止。

発掘対象は同心円状の帯として中央に配置し、その帯の中のどこからでも発掘できるようにします。特定の画面端の一区画だけを次の必須目標として指定しないでください。

縦向きと横向きでは、垂直FOVと水平FOVの両方から必要なカメラ距離を計算してください。モザイクの外縁と中央円盤のせり上がりを含む最大範囲が必ず画面内に収まるようにします。

クライマックスでもモザイクの中心を画面中央に維持します。演出の途中で主役を見切れさせないでください。

## 7. 操作と入力処理

iPad SafariおよびPCブラウザに対応してください。2020年世代のiPad Proを性能上の主要な想定端末とします。

入力にはPointer Eventsを使用し、タッチとマウスを共通処理してください。

- `pointerdown`、`pointermove`、`pointerup`、`pointercancel`に対応。
- 最初のpointerIdのみを操作に使用する。
- 2本目以降の指は無視する。
- Pointer Captureを使用する。
- Raycasterで発掘面との交点を求める。
- 当たり判定は送風機の見た目の1.5〜2倍程度。
- タップ判定領域は最低56 CSS px程度を確保する。
- 指で隠れる位置から送風機本体を少しずらし、砂が飛ぶ様子を視認できるようにする。

画面全体で`touch-action: none`、`user-select: none`、`overscroll-behavior: none`などを適用してください。

ピンチズーム、ダブルタップズーム、スクロール、長押しによるコンテキストメニュー、テキスト選択をゲーム内で抑制します。

画面回転、タブ切り替え、タッチ中断などが発生した場合にも、送風機が動作し続ける不具合が生じないようにしてください。

## 8. 音響設計

音声ファイルは使用せず、WebAudioによってすべて手続き的に合成してください。

最初のユーザー操作でAudioContextを生成またはresumeします。

### 環境音と効果音

| 音 | 合成方法の目安 |
|---|---|
| 砂漠の風 | フィルター処理したピンクノイズ |
| 送風機の回転 | 80〜150Hz程度の基音と倍音 |
| 送風音 | 400〜2500Hz程度の帯域を持つノイズ |
| 砂粒の飛散 | 短い高域ノイズをランダムに重ねる |
| 色石の発見 | 正弦波と三角波による澄んだ音 |
| 金細工の反射 | 減衰する複数の高域倍音 |
| クライマックス | 上昇するアルペジオと広がりのある和音 |

成功音は、第1段階ではC5〜E5程度の単音、第2段階では2音、第3段階では長三和音、第4段階では付加音を含む和音へと発展させます。

クライマックスではC4、G4、C5、E5、G5、D6などを時間差で鳴らし、広大な空間に響くような音を作ってください。

ConvolverNode用のインパルス応答も手続き的に生成できます。残響時間は通常0.5〜0.8秒、クライマックスでは1.5〜2.0秒程度とします。

BGMは砂漠の風と控えめな持続音を中心にし、送風や砂粒の効果音が埋もれないようにしてください。

突然の大音量、刺激の強い高周波音、警告音は使用しません。マスター出力にはコンプレッサーを適用し、音割れを防止してください。

## 9. 画面の文字とUI

ゲーム画面には文字、数字、スコア、進捗バー、ボタンのラベル、タイトルを一切表示しません。

進捗は、発掘されたモザイクそのものによって伝えてください。

開始、操作誘導、段階の変化、成功、完成、再プレイのすべてを、実物の動き、光、色、音だけで理解できるようにします。

画面全体を一つの3Dの世界として扱い、ゲーム用の操作パネルを重ねないでください。

## 10. 画質の自動調整と高速化

iPad Safariで50fps以上を目標とし、理想的には60fps付近を維持してください。

画質設定をhigh、mid、lowの3段階で用意します。

| 項目 | high | mid | low |
|---|---:|---:|---:|
| デバイスピクセル比上限 | 1.75 | 1.25 | 1.0 |
| シャドウマップ | 2048² | 1024² | 簡易接地影 |
| 砂粒の同時表示上限 | 2400 | 1000 | 400 |
| 光粒子の上限 | 500 | 250 | 100 |
| モザイク石片数の目安 | 2400 | 1200 | 600 |
| 雲の詳細度 | 高 | 中 | 低 |
| ブルーム | 有効 | 低解像度 | 疑似発光 |
| 砂の法線表現 | 高精細 | 中精細 | 簡略化 |

lowでも発掘区画数、発掘範囲、模様の主要な形状、成功演出は維持してください。画質を下げてもゲーム内容を削らないこと。

起動時はmidを基準とし、最初の数秒の描画性能から調整します。実行中もフレーム時間を計測してください。

- 48fps未満が約3秒続いた場合：1段階下げる。
- 57fps以上が約10秒続いた場合：1段階上げることを検討する。
- 画質変更後は10秒程度のクールダウンを設ける。
- クライマックス中の一時的な負荷には、粒子数と描画解像度の調整を優先する。

URLパラメータ`?q=low`、`?q=mid`、`?q=high`で画質を強制指定できるようにします。強制指定時は自動画質変更を停止してください。

粒子にはオブジェクトプールを使用し、毎フレームのオブジェクト生成、ジオメトリ再生成、GPUへの不要なデータ転送を避けてください。

## 11. 技術構成

### 11.1 ファイルとライブラリ

実装先は以下の1ファイルとします。

`site/games/e07/index.html`

HTML、CSS、JavaScript、シェーダー、プロシージャル生成処理をこのファイルにまとめてください。

Three.jsはリポジトリ同梱のものを使用し、importmapで以下を参照してください。

| import名 | 参照先 |
|---|---|
| `three` | `../../vendor/three/build/three.module.min.js` |
| `three/addons/` | `../../vendor/three/examples/jsm/` |

CDN、外部画像、外部3Dモデル、外部音声、外部フォント、外部APIは使用禁止です。

`<head>`内に次の要素を必ず追加してください。

`<meta name="robots" content="noindex">`

`</body>`の直前には次のスクリプトを必ず追加してください。

`<script src="../../gf-playlog.js" defer></script>`

既存の共通ライブラリやログ記録処理を独自実装で置き換えないでください。他のゲームのファイルも変更しないこと。

### 11.2 状態管理

ゲームの状態は以下の順序を基本とします。

`INTRO → STAGE_1 → STAGE_2 → STAGE_3 → STAGE_4 → CLIMAX → FREE_PLAY → RESET → INTRO`

各区画の砂の残存量、発掘完了状態、成功演出の実行状態は個別に管理してください。

同一区画の成功判定を重複して発生させないこと。ゲームをリセットしたときは、粒子、音声、タイマー、アニメーション、発掘データを適切に初期化してください。

乱数シードを使用し、テスト時に同じ初期状態を再現できる設計を推奨します。

### 11.3 準備完了とエラー管理

以下のグローバル変数を必ず用意してください。

- `window.__ready`：初期値false。初期化が完了し、最初の3Dフレームが正常に描画され、入力可能になった時点でtrueにする。
- `window.__errors`：初期値は空配列。JavaScriptエラーや未処理のPromise rejectionなどを記録する。

エラー監視はThree.jsの初期化より前に設定してください。

### 11.4 自動プレイ

URLに`?autotest`を指定すると、自動プレイを実行してください。

通常操作と共通の発掘処理を利用して、全28区画の発掘、4段階の進行、中央円盤の回転、クライマックス、フリープレイへの移行を検証します。

進行状態を直接書き換えて完成扱いにする方法は禁止です。実際の砂の除去処理、成功判定、演出を通過させてください。

画面にテスト用の文字は表示しません。ブラウザの音声自動再生制限がある場合は、無音でも自動テストを続行できるようにしてください。
