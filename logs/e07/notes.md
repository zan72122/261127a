# E07 すなばくに ねむる たからもの — 実装メモ

実装: `site/games/e07/index.html`（HTML + CSS + JS を1ファイル。Three.js r0.187.0 同梱版を importmap で読み込み。CDN・外部画像・外部モデル・音声ファイルなし）

## 実装の要点

- **遊び**: 砂に埋もれた直径14mの円形モザイク（＋砂岩の枠で直径約15.2m）を、真鍮の送風機で吹いて発掘する。指が触れている間は自動で送風（離すと0.3秒で停止）。タップでも一度に砂が飛ぶ。開始メニューなし、最初のタッチでそのまま開始。
  - 砂は 256×256 の動的マスク（厚み）で管理。楕円の扇形ブラシ（段階ごとに幅 1.0/1.3/1.6/1.8m、指が速いほど広がる）で厚みを連続的に減らし、指の移動経路に沿ってスタンプを補間。砂の面はマスクで頂点を持ち上げたメッシュ（法線も高さから計算）なので、厚みのある砂の壁が削れていくように見える。薄い所は粒状に抜けて石が見える。
  - 除去量に比例して粒子を出す（細かい砂粒＝速く飛ぶ、大きい砂粒＝放物線で落下・着地、砂煙＝広がって消える、最大不透明度 0.19）。プール方式・上限は画質ごと（2400/1000/400）。除去した量に応じてモザイクの外側に砂がわずかに積もる。
  - 28区画（4段階×7区画、同心円の帯）。各区画 82% 除去で成功 → 残りを0.55秒で吹き飛ばす・区画の金の縁に光が走る・成功音・金の光粒子。段階完了で帯全体を光が一周（第2段階は内周と中周がつながる）。順序は強制せず、先の段階を掘っても保存。
  - 放置時の誘導: 2.5秒 砂の隙間から石がきらめく／4秒 その辺りの砂が揺れる／6秒 送風機がそちらを向きファンが回って砂がふわっと舞う／以後くり返し。誘導だけで区画は完成しない。
  - クライマックス（12秒）: 0〜2秒 中央の砂粒が吹き飛ぶ → 2〜5秒 中央円盤が0.15mせり上がり毎秒20°で回転 → 5〜7秒 太陽の意匠が輝く → 7〜9秒 光の波が内周・中周・外周へ → 9〜10秒 全体が輝き金の粒子 → 10〜12秒 落ち着く。その後フリープレイ（吹くと微細な砂と光の粒が舞う）、10秒操作がなければ風が約10秒かけて砂を戻し、最初の状態（青い石が一部見える）に戻る。
- **絵作り**: 空はグラデーション＋太陽のシェーダー、積雲はノイズで変形した球の集合（下が平ら、陰が青灰色、縁の光）。地形は「発掘現場のある台地 → 谷へ下る → 谷に赤褐色の岩山（水平な地層の色、浸食された凹凸）→ 霞の地平線と、その向こうから立ち上がる積雲」。砂は手続き生成の色と風紋の法線マップ。モザイクは InstancedMesh の面取り石片（low 約1500 / mid 1900 / high 2600、厚み0.025〜0.07m、目地・高さのばらつき・わずかな傾き）。石の種類ごとに模様をシェーダーで追加（ラピスの金の斑点、トルコ石の母岩の筋、瑪瑙の縞、真珠母貝の見る角度で変わる虹色、金の傷）。周囲に砂が残っている石は暗くなる（掘った穴の感じ）。
  - 送風機: 真鍮の胴・吸気口の中で回るファン・細くなるノズル・銅のリングとボルト・木の持ち手。指の位置を0.1秒で追い、本体は画面上で指より奥側に浮かぶ（指で隠れない）。送風中は振動。
  - 時間帯: 発掘の進み具合に合わせて太陽仰角 55°→42°→28°、色・空・光の強さを指示文の表どおりに連続変化。環境マップはこの空と雲から PMREM で生成（時間帯が一定以上変わったとき再生成）。
  - **白飛び対策（前回の反省）**: ACESFilmic、露出 0.96（最大でも +0.03）、ブルームは最大 1.1・しきい値 0.92。画面全体のフラッシュなし。光は石片の発光（金細工を中心、色石は自分の色）で表現し、全体発光の色石への寄与を小さくした。クライマックス最大時のスクリーンショットで、太陽の意匠・各色石・輪郭・空/雲/岩山が見えることを確認。
- **カメラ**: モザイク中心を常に画面中央に置く固定軸。縦横どちらでも、外縁（せり上がり分を含む）が画面短辺の65〜80%に入るよう、毎フレーム距離を計算（縦横の視野角の両方で判定）。段階が進むと少しずつ引く。クライマックスとフリープレイは、レンズシフト（`setViewOffset`）で「モザイク中心は画面中央のまま」空・岩山・積雲が上部に入る構図にする。ロール0、補間約2秒。
- **入力**: Pointer Events、最初の pointerId のみ、setPointerCapture、pointercancel / lostpointercapture / blur / タブ非表示 / 画面回転で送風停止。touch-action・選択・長押し・ダブルタップ・ピンチを抑止。
- **音**: WebAudio のみ（最初のタッチで生成/resume）。風（ピンクノイズ）、控えめな持続音、送風機のモーター（80〜155Hz＋倍音）、送風（帯域ノイズ）、砂粒（短い高域ノイズ）、発見音（ペンタトニック）、成功音（段階ごとに 単音＋倍音 → 2音 → 三和音＋金属の余韻 → 付加音つき和音）、クライマックス（C4 G4 C5 E5 G5 D6 のアルペジオと和音、長い残響）。手続き生成のインパルス応答（0.7秒／1.8秒）、マスターにコンプレッサー。
- **画質**: `?q=low|mid|high` で固定（自動調整停止）。指定なしは mid で開始し、48fps未満が3秒で1段階下げ、57fps以上が10秒で上げる（クールダウン10秒、クライマックス中は上げない）。high: PR1.75/影2048/ブルーム、mid: PR1.25/影1024/半解像度ブルーム、low: PR1.0/影なし（送風機の簡易接地影）/ブルームなし（発光のみ）。
- **状態**: INTRO → STAGE_1〜4 → CLIMAX → FREE_PLAY → RESET → INTRO。`window.__ready`、`window.__errors`（Three.js より前に監視開始）、`window.__test`（state, done, climax, peak, free, reset, intro2 など）。`?autotest` は通常と同じ onDown/onMove/onUp に合成イベントを流し、全28区画を実際に吹いて発掘（第2段階の1区画はタップのみ、各段階で1回「指を止めたまま」も試す）→ クライマックス → フリープレイ → 放置で砂が戻り INTRO まで。乱数はシード固定。
- **画面の文字**: なし（読み込み中は金色の円が脈打つだけ）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright ヘッドレス Chromium（SwiftShader）で `games/e07/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で全工程実行。結果は `logs/e07/test.txt`。テストスクリプトは `logs/e07/run-test.js`。
- **横・縦とも PASS**: `__ready === true`、`__errors` 空、コンソールエラーなし。28区画発掘 → クライマックス（最大の光の瞬間に到達）→ フリープレイ → 砂が戻って INTRO まで。各約3分。
- `q=mid`・`q=high` は開始〜数区画（約30秒）を実行し、`__ready`、エラーなし、コンソールエラーなしを確認（影・ブルーム有効で成功時の光が白飛びしないことも目視）。全工程は未実行。
- スクリーンショット: `shot-1.jpg`（序盤・3区画）、`shot-2.jpg`（中盤・15区画）、`shot-3.jpg`（クライマックス約9秒＝最大の光付近）、`p-shot-1〜3.jpg`（縦の同場面）。すべて 300KB 以下の JPEG。縦横ともモザイクが画面中央にあり見切れていない。
- サムネイル: `site/thumbs/e07.jpg`（クライマックスの画面を 640x480 に縮小、約70KB、文字なし）。
- 禁止語4語（ひらがな・カタカナ表記を含む）が `site/games/e07/` と `logs/e07/` にないことを grep で確認。
- 外部通信: ゲーム本体は外部にアクセスしない。共通の `../../gf-playlog.js` のビーコンだけはテストで 204 を返して代用。

## 未解決・注意点

- iPad Safari 実機での動作・FPS・タッチ感触は未確認（SwiftShader は CPU 描画で 2〜5fps のため性能の指標にならない）。
- 自動テストとスクリーンショットは q=low（影・ブルームなし）なので、画像は実際の mid/high より平板に見える。クライマックスの光も low では発光のみで控えめ。
- 指示文との差: クライマックス／フリープレイのカメラは見下ろし角が約37°（指示文は50〜65°）。50°以上だと空・岩山・雲がまったく画面に入らないため、レンズシフトで中心を保ったまま角度を浅くした。プレイ中は56°〜44°。送風機は見やすさのため全長約1.45m（指示文 0.9〜1.2m）。ブルームしきい値は 0.92。
- 石片数は起動時の画質で決まり、実行中に画質が変わっても作り直さない。
- 空は「地平線の霞」の帯が中心で、深い青は上端の一部にしか出ない（構図上の制約）。
