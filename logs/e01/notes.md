# E01 たいようの こおりのはな — 実装メモ

実装: `site/games/e01/index.html`（HTML + CSS + JS を1ファイル、Three.js r0.187.0 同梱版を importmap で読み込み）

## 実装の要点

- **遊び**: 中央の六回対称の巨大な氷の結晶に、指1本で氷晶を運んではめる。全3段階 × 6回 = 18回装着。
  - 第1段階: 短い六角柱の氷晶（中心核のまわり）/ 第2段階: 側枝つきの細長い氷晶 / 第3段階: 先端が多面体のプリズム状氷晶。
  - 装着した氷晶は最後まで残り、結晶がだんだん大きくなる。
  - 次に運ぶ氷晶は画面中央下（縦 約77%）に浮かび、稜線とうしろの光で強調。装着箇所は同じ色の光と枠（ゴースト）で示す。
  - 向きは自動で装着箇所に合わせる（回転操作なし）。吸着範囲は見た目より広く、近づくと磁石のように引き寄せ、範囲に入った時点で成功確定（指を離さなくてよい）。吸着アニメは 240ms の ease-out。
  - 途中で離した / 遠くで離した → 0.5 秒で元の位置へ戻るだけ（失敗表現なし）。タップで選択 → 装着箇所タップ の補助操作あり。
  - 2.5 秒無操作で氷晶がゆっくり上下、5 秒で氷晶から装着箇所へ光の粒が流れる（自動では装着しない）。
  - 装着ごとに: 澄んだ打音 → 光が結晶内部を走って中心核へ → 既存の枝へ伝播（第2段階以降は隣の枝にも）→ 水面・氷壁へ反射光。成功後に結晶を 60 度ずつ回して次の接続部を手前に。
  - 段階の完成: 第1段階は中心核全体が光り、岩場と水面に光の輪。第2段階は稜線が順番に光り、氷壁へ反射光。第3段階は各先端から6色（青・青緑・緑・金・桃・紫）の光の帯。
  - クライマックス（約21秒）: 6方向の光が中心へ集中 → 中心核が金色に満ちる → 枝へ一斉に光 → 結晶が垂直軸でゆっくり1回転 → 峡谷全体（氷壁・岩・水面）に色の光の模様が広がる → 穏やかに収束。カメラは 2〜9.5 秒で 1.45 倍まで後退（急な動き・揺れ・ロールなし）。
  - 余韻 10 秒 → フリープレイ（枝をタップすると先端から中心へ光と音、中心をタップで全体がきらめく和音）→ 約16秒無操作で光の粒が空へ舞い上がり、初期状態へ戻って繰り返し遊べる。
- **状態管理**: LOADING / WAIT_START / WAIT_INPUT / DRAGGING / SNAPPING / SUCCESS_EFFECT / STAGE_TRANSITION / CLIMAX / AFTERGLOW / FREE_PLAY / RESETTING。自動テストも通常と同じ pointer 処理（onDown/onMove/onUp）を合成イベントで通す。
- **絵作り**: 空はシェーダーのグラデーション＋太陽＋ゆっくり流れる雲。氷河の壁と遠方の氷山はノイズで変形した BufferGeometry（縦の筋、うねり、上部の雪、下部の濃い青緑）。水面は 2〜4 波の合成＋フレネル＋空と氷壁の擬似反射＋太陽のきらめき。岩場は灰青色で水際が濡れた色。氷は MeshPhysicalMaterial（ior 1.31、attenuation、clearcoat、手続き生成の法線マップ）、結晶内部に気泡・亀裂・成長層。環境マップは空シーンから PMREM で生成（段階が変わったときだけ再生成）。
  - 色は指示文の段階別パレット（空・地平線・太陽・氷・深部・霧・水面）を段階の進行にあわせて補間。
  - トーンマッピング ACESFilmic、露出 1.0（クライマックス最大 1.06）。ブルーム強度は通常 0.32〜0.42、クライマックス最大でも 1.1 を超えない（`Math.min(1.1, …)`）。
  - **白飛び対策（前回の反省）**: 画面全体のフラッシュはなし。ブルームのしきい値はリニア HDR 値で 2.6 にして、日の当たる雪や空ではなく結晶の光だけがにじむようにした（指示文の 0.85〜1.0 だと同梱版の HDR 描画では画面全体が白くかすんだため調整）。クライマックス最大の瞬間のスクリーンショットでも六角形の結晶・空の青・氷河の輪郭・水面が見えることを確認。
- **カメラ**: 画面比から縦横の FOV を計算してカメラ距離を決める（結晶全体が幅・高さの 85% 以内、結晶中心は縦 45%）。縦画面・横画面とも結晶が中央。運ぶ氷晶と待機中の氷晶の位置も画面比ごとに計算。
- **音**: WebAudio のみ（最初のタップで AudioContext 生成/resume）。正弦波＋三角波＋少量の倍音のガラスのような打音、C メジャー・ペンタトニック。第1段階は単音、第2段階は三度・五度、第3段階はオクターブを含む和音、完成時は Cmaj9 系のゆっくり立ち上がる和音。ノイズを濾過した風と水の環境音（小音量）。マスターゲイン＋DynamicsCompressor。
- **操作**: Pointer Events、pointerId を保持して2本目の指は無視、setPointerCapture、当たり判定は見た目の 1.5 倍（最小半径 36px＝直径 72px）。touch-action / overscroll / user-select / callout を無効化、gesture・dblclick・contextmenu を抑止。タッチ時は氷晶を指より少し上に表示。
- **画質**: `?q=low|mid|high` で固定（自動調整なし）。指定なしは mid 起点（描画能力が低ければ low）。rAF 間隔の EMA で約3秒 48fps 未満なら1段階下げ、約10秒 57fps 以上なら上げる（クールダウンあり、ドラッグ中・クライマックス中は変更しない、0.25 秒超の異常間隔は除外）。high: PR1.75 / 影1024 / ブルーム / 粒子500 / 透過は結晶と部品 / 波4。mid: PR1.25 / 影512 / ブルーム半解像度 / 粒子240 / 透過は中心核 / 波3。low: PR1.0 / 影なし / ブルームなし（スプライトの疑似発光）/ 粒子100 / 疑似透過 / 波2。遠景の形状精度は起動時の画質で決定。
- **画面の文字**: なし（ロード中は CSS の光る六角形のみ）。`window.__ready` / `window.__errors` / `window.__test`（state, stage, attached, fps, quality, errors, climaxReached, freePlayReached, done など）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright のヘッドレス Chromium（SwiftShader: `--use-angle=swiftshader --enable-unsafe-swiftshader`）で `games/e01/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で実行。結果は `logs/e01/test.txt`。
- 両方とも `__ready === true`、`__errors` 空、コンソールエラーなし、18回装着 → クライマックス → 余韻 → フリープレイ（タップ4回）→ 初期状態への復帰 → 再び開始待ちまで到達。（詳細は test.txt の RESULT 行）
- スクリーンショット: `shot-1.jpg`（序盤・横）、`shot-2.jpg`（第3段階・横）、`shot-3.jpg`（クライマックス約12秒・横）、`p-shot-1〜3.jpg`（同じ場面・縦）。縦横とも結晶は画面中央で見切れず、クライマックス最大時も空の色と結晶の形が見える。
- `q=mid`（透過＋ブルーム）も開始画面で表示・エラーなしを確認。
- FPS: SwiftShader（CPU 描画）なので 4〜5fps しか出ず、実機の性能指標にはならない。**iPad 実機での FPS 測定はできていない。**
- 依頼で指定された禁止語4語（ひらがな・カタカナ表記を含む）が `site/games/e01/` と `logs/e01/` に含まれないことを grep で確認。
- 外部通信: ゲーム本体は外部に一切アクセスしない。必須の共通スクリプト `../../gf-playlog.js` だけが外部へビーコンを送る（このサンドボックスではプロキシで遮断されコンソールに `ERR_TUNNEL_CONNECTION_FAILED` が出るため、テストではそのリクエストだけ 204 で代用した）。

## 未解決・注意点

- iPad Safari 実機での動作・FPS・タッチ感触は未確認（ヘッドレス Chromium のみ）。high / mid の透過マテリアルとブルームの負荷は実機で要確認。
- 自動テストは q=low のみ全工程を通した。mid は開始画面の表示確認のみ、high は未実行。
- 低 FPS 環境ではゲーム時間を1フレーム最大0.1秒（autotest は0.2秒）に制限しているため、極端に遅い端末では演出がゆっくりになる。
- デバッグ用に `?autotest` または `?dbg` のときだけ `window.__dbg` を公開している（画面表示はなし）。
