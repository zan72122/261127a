# E11 アルプスの おおきなかぜのオルガン — 実装メモ

実装: `site/games/e11/index.html`（HTML + CSS + JS を1ファイル。Three.js 同梱版を importmap で読み込み。CDN・外部画像・外部モデル・音声ファイルなし）

## 実装の要点

- **遊び**: 石の円形広場の中央にある巨大な風のオルガン（幅約8m・高さ約9m、銀色のパイプ5本、革のふいご）。ふいごの上板を指で下へ押すと、蛇腹の各折り目が連動して閉じ（折り目の稜線が外へ張り出す構造を毎フレーム計算）、真鍮の導管に光が走ってパイプが鳴る。
  - 下方向ドラッグ（画面サイズに応じて60〜110px）で圧縮。タップ・長押しでも約0.85秒の自動圧縮で演奏できる。圧縮70%で演奏成立、残りは自動で押し切り、ふいごは段階に応じて1.8〜1.45秒で膨らみ直す。
  - 押し始めの木と革の音 → 圧縮中の空気音（圧縮速度と量でフィルターが変化）→ 押し切りの低い機械音 → パイプの発音（息の音＋音色）→ 吸い込む音。
  - 発音と同時に、オルガンから風の波（同心円）が広がる。草（頂点シェーダー、根元固定で先端がしなる）、花、旗、リボン、小川のさざ波、花びらと綿毛の粒子が、波が届いた順に反応する。旗は近いものから遠いものへ遅れて広がる。風の届く距離は段階ごとに 16m → 30m → 95m → 260m。
  - 5本のパイプ（C3, E3, G3, C4, E4）は1回に1本ずつ加わり、鳴らしたパイプは控えめな持続音と縁の淡い光で残る。5本目で長三和音と大きな風。進行は光・旗・風・音だけで示す（文字・数字なし）。
  - 全4段階×5回＝20回。段階移行では音を静めてから次の段階へ（時間帯が午前 → 正午 → 午後 → 黄金色の夕方へ数秒かけて補間、花が少しずつ育ち、蝶が増え、そよ風が少し強くなる。景観の変化は維持）。段階ごとに倍音（PeriodicWave）、残響（2種類のプロシージャル IR）、フィルターが豊かになる。
  - **クライマックス（約18.5秒）**: 0〜2秒 5本の導管に空気が送られる → 2秒 全パイプ＋ペダル低音＋高音の重なり → 5秒 高原全体へ大きな風の波 → 9〜14秒 金色の綿毛と花びらが舞い上がり、パイプを金色の光が順に駆け上がる → 14秒以降 穏やかに。カメラは中央を保ったまま12%ゆっくり引く。余韻6.5秒 → フリープレイ（5本を順に鳴らし、5回ごとに和音と大きな風）。
  - 放置2.8秒で誘導: ふいご上面の真鍮プレートが光り、上板がわずかに沈み、次のパイプへの導管に光が少し流れる。
  - 失敗なし: ふいご以外のタップは何も起きない。途中で指を離しても自動で押し切る。演奏中は入力を受け付けない（膨らみ直しの後半からは次の操作を受け付ける）。2本目以降の指は無視。
- **絵作り**: 空はシェーダー（天頂・地平線・太陽・ノイズの雲）。雪山は極座標メッシュ7峰（峰ごとのガウス＋ridged ノイズ）で、高さと傾きから草地・森・岩肌・雪・雪の陰影を頂点色で塗り分け。高原は起伏のある地面、遠景の丘、小川（二方向以上の法線ゆらぎ、フレネル、浅瀬の色）。草は InstancedMesh（3枚の葉の束）、花はデイジー・キンポウゲ・クロッカスの3種（花弁・花芯・茎・葉を分けた形）。
  - 木目・革（縫い目つき）・石畳・パイプの研磨跡の法線はすべて canvas で手続き生成。金属の反射は、空・地面・山並み・太陽の環境を PMREM で作って使用（時間帯が変わったときだけ更新）。
  - 遠くの小鳥5羽、蝶（段階で増える）。人物・乗りもの・城・ブランド・キャラクターなし。
  - **白飛び対策（前回の反省）**: ACESFilmic、露出は最大1.10、Bloom は high でしきい値0.88・強さ最大1.0（mid は0.75倍、low はなし）。光はパイプの縁・導管・粒子・小さな局所光だけ。クライマックスのスクリーンショット（shot-3 / p-shot-3、サムネイル）で、雪山の稜線・パイプの形・空の青が見えることを確認。
- **カメラ**: 方位固定・ロール0・急な動きなし。オルガンの外形（パイプ先端〜ふいご下端・左右の柱）が上下左右9%の余白に収まり、ふいごの上面が画面の高さ57%に来る距離と注視点を、画面比ごとに数値探索で決める（縦画面は自動で引く）。
- **入力**: Pointer Events、setPointerCapture、最初の pointerId のみ。当たり判定は見た目より約27〜30%広い（最小140px）。pointercancel / lostpointercapture / blur / タブ非表示で安全に解除。touch-action・選択・長押し・ダブルタップ・ピンチ・スクロールを抑止。
- **音**: WebAudio のみ。最初のタップで AudioContext を作成・再開（失敗してもゲームは続く）。コンプレッサー＋マスターゲイン。環境音は風（風の強さに連動）、小川、遠くの小鳥のみ。タブ非表示で減衰・停止し、復帰で再開。
- **画質**: `?q=low|mid|high` で固定。指定なしは mid で開始し、50fps 未満が3秒で1段階下げ、58fps 以上が15秒で上げる（切り替え後12〜20秒待機）。high: PR上限1.75・影2048・Bloom・草25000・花1200・粒600、mid: 1.25・1024・軽いBloom・10000・500・250、low: 1.0・影なし（接地影の板）・Bloomなし・4000・200・100。ふいご・パイプ・旗・進行は全画質で同じ。
- **状態**: IDLE / COMPRESSING / RELEASING / REFILLING（ふいごの共通処理）と STAGE_TRANSITION / CLIMAX / AFTERGLOW / FREE_PLAY。`window.__ready`、`window.__errors`、`window.__test`（state, count, stage, climax, peak, afterglow, free, freeChords, centerErr, inFrame, bellowsY など）。
- `?autotest`: 通常の pointerdown / move / up に合成イベントを流して20回演奏（タップ・ドラッグ・長押し・短いドラッグを順に。途中でふいご以外のタップ1回、2本目の指1回）→ クライマックス → 余韻 → フリープレイで5回（和音1回）→ `finished`。進行はコンソールに `[e11]` / `[autotest]` で出力。
- 確認用に `?pre=N`（N回演奏済みから開始、20ならクライマックスから。`&ct=秒` で途中から）を用意（autotest では無効）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright ヘッドレス Chromium（SwiftShader）で `games/e11/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で全工程実行。結果は `logs/e11/test.txt`、スクリプトは `logs/e11/run-test.js`。
- **横・縦とも PASS**: `__ready === true`、`__errors` 空、コンソールエラーなし、20/20 → クライマックス（ピーク到達）→ 余韻 → フリープレイ（和音1回）→ finished。オルガン中心の水平ずれ 0px、外形が画面外に出たフレーム 0、ふいご上面は画面の高さ 57〜58%。合成の2本目の指を無視1回・ふいご外タップ1回も記録。所要 横220秒・縦234秒（約5fps）。
- `q=mid`・`q=high` は横で最初の数回の演奏まで実行し、エラーなしを確認（test.txt 末尾）。
- スクリーンショット: `shot-1.jpg`（序盤）、`shot-2.jpg`（中盤・12回後）、`shot-3.jpg`（クライマックス約11秒）、`p-shot-1〜3.jpg`（縦）。すべて 300KB 以下の JPEG。
- サムネイル: `site/thumbs/e11.jpg`（high 画質のクライマックス、640x480、約63KB、文字なし）。
- 禁止語（ひらがな・カタカナ表記を含む）が `site/games/e11/` と `logs/e11/` にないことを grep で確認。

## 未解決・注意点

- iPad Safari 実機での動作・FPS・タッチの感触・音は未確認（SwiftShader は CPU 描画のため性能の指標にならない。自動テストでは音声の発音そのものは検証していない）。
- 自動テストのスクリーンショットは low 画質（Bloom・影なし）なので、mid/high より平板に見える。
- iPhone 相当（390x844）は全工程の自動テスト未実行（構図の計算は同じ仕組み）。
- 指示文との差: オルガン全体の画面占有幅は、ふいごを画面高さ57%に置きつつパイプ先端に余白を取るため、横画面で約45%（指示文の目安は55〜80%）。山は空の見える範囲に収めるため実際のアルプスより低め（約60〜110m）。
