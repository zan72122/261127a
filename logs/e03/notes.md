# E03 にじいろ おんせんオーケストラ — 実装メモ

実装: `site/games/e03/index.html`（HTML＋CSS＋JS＋シェーダーの1ファイル。Three.js は同梱版を importmap で読み込み。CDN・外部画像・モデル・音声ファイルなし）

## 実装の要点

- **舞台**: 高原の石灰華の段丘（多周波ノイズ＋段差関数で 0.4m 前後の段を作る）に、直径 5〜7m の温泉を5つ、緩い扇形（中央が奥）に配置。間欠泉どうしは約 8.7〜10m。各温泉の周りだけ高解像度の極座標メッシュ（縁の盛り上がり・二段目の段丘）を重ね、粗い全体地形は温泉の下で少し下げて突き抜けを防いでいる。遠景は草原のリングと、霞んだ山並み（ライティングなし・頂点色）。
- **地面の色**: 頂点色で乳白色の石灰華、温泉の縁に黄土色・琥珀色・赤褐色の帯（ノイズで揺らす）、温泉の下流側に鉱物の流れ跡、段差の面に湿った岩肌色。`aWet` 属性で湿った部分の roughness を 0.34 に下げる（onBeforeCompile）。微細な凹凸は Canvas で生成したタイル状ノーマルマップ（normalScale 0.22）。
- **温泉の水**: 自前シェーダー。深さ（池の中心からの距離で推定）による吸収で浅瀬 #48DCCB → 深部 #078DA8、浅い所は底の鉱物（琥珀色）が透ける。正弦波の法線（low 1層 / mid 2層 / high 3層）＋ノイズ、Fresnel、空のグラデーション反射、太陽の鏡面反射（光の筋）、コースティクス、着水点からの同心円の波紋（16個のリングバッファ）。一度噴いた温泉は彩度と輝きが上がる（目覚め）。
- **空**: 球体シェーダー（天頂〜地平線の勾配、太陽、fbm の雲がゆっくり流れる）。環境マップは同じ空を PMREM で焼き、時間帯が進んだときだけ焼き直す（毎フレームの反射カメラなし）。
- **時間帯**: 指示文の朝・午前・午後の色（天頂・地平線・太陽光・霧・光の強さ・仰角）を段階の進行に合わせて連続補間。夜はない。
- **ポンプ（5台）**: 真鍮・銅・磨いた金属・ガラスの架空の機械。大きな円形ピストン（上面にアクセント色の発光板）、ガラス円筒の中で上がる水、文字のない圧力計と針、ピストンの周りの発光リング（充填率に応じて一周する）、間欠泉へつながる銅の配管（中を光が走る）。アクセントはターコイズ・琥珀・エメラルド・サファイア・ローズゴールド。
- **水柱**: 時間で変形する半透明の芯メッシュ＋外側の薄い水膜（頂点シェーダーでノイズ変形、フラグメントで泡の筋・逆光・きらめき）、Points の水滴（頂点付近で四方に開く冠、柱からはがれる膜、根元のしぶきの3種類。初速度＋重力 9.8 の弾道計算、着水で波紋と小さな音）、根元の水煙。
- **虹**: 「虹の中心点」から見た角度で色を決める帯を、水滴そのもの（Points の色）と、水煙の範囲だけに出す加算の板（ノイズでまだらにする）の両方に適用。独立した不透明なアーチにはしない。第1段階は小さく、第2段階は水柱を囲む大きさ、第3段階とクライマックスは温泉地帯にまたがる大きな虹。噴射後 1.5 秒ほど残って消える。
- **蒸気**: Points の半透明スプライト（ノイズ入り）。逆光で縁が光る。次に触るポンプの画面位置の周りでは蒸気を薄くして、操作対象を隠さない。
- **操作**: Pointer Events（pointerdown/up/cancel/lostpointercapture、Pointer Capture、二本目以降は無視）。当たり判定はポンプの縦の線分からの距離で、半径は max(44px, 見た目の1.5倍)。途中で離すと圧力はそのまま READY に戻り、続きから充填。満タンでは勝手に噴かず、指を離した瞬間（同じフレーム）に配管の光・ピストンの戻り・水柱・噴射音が始まる。pointercancel・画面回転・アプリ切り替えでは噴射せずに解除。ズーム・スクロール・長押しメニュー・ダブルタップは抑止。
- **段階**: 長押し 1.6 / 2.2 / 2.8 秒、水柱 約4.6 / 9.2 / 14m（15回目は 15m）。第2段階は以前の間欠泉が一度だけ小さく応答、第3段階は周りの4つが順番に応答。最後の充填中は全間欠泉の根元から蒸気と、全配管に順番に光が走る。
- **クライマックス（30秒）**: 0〜4秒 最後の水柱 15m → 4〜10秒 5本が順番に（各音程）→ 10〜16秒 左右が交互（100 BPM）→ 16〜22秒 波のように連続 → 22秒 全部が約17mで同時 → 23秒 温泉地帯をまたぐ虹 → 25〜30秒 水滴が降り注ぐ。その後 8 秒の余韻、3 秒で朝の景色と初期状態に戻り、中央のポンプが再び光る。
- **カメラ**: 斜め上からの透視（垂直 FOV 横 42° / 縦 48°、ロール 0、揺れなし）。操作前は、ポンプ・その段階の最大噴射高さ・水滴の広がり・温泉を画面に投影し、上下左右 9% の余白に収まる最短距離を二分探索で求め、さらにポンプが画面中央 30% に入る範囲で注視点の高さを選ぶ。長押し中はカメラ固定。噴射後は水柱の中心へ 1.4 秒で移動。クライマックスは5本×17m＋大きな虹が入る構図。縦横の切り替え時に再計算。
  - 俯角は空の色を画面に入れるため、指示文の 25〜35° より浅い 14°（クライマックス 11°）にしている。
- **音（WebAudio のみ）**: 最初のタップで AudioContext を作成/再開（そのタップはそのままポンプ操作にも使う）。温泉の水音・風（ノイズ）、ピストンの「ゴトン」と金属音、圧力上昇の連続音（25〜50% で水音、75% 以上で倍音）、満タンのベル、噴射音（帯域の違うノイズ3本）、着水のプチ音、虹のアルペジオ、ヒントのチャイム。音程は C4 D4 E4 G4 A4（ペンタトニック）。第1段階は単音、第2段階は和音、第3段階はオクターブとアルペジオ。マスター 0.28 → コンプレッサー。
- **光**: ACESFilmic、SRGB、露出 1.0（クライマックス 1.05）。Bloom は threshold 0.9、radius 0.35、通常 0.35 → 成功時 ~0.68 → クライマックス 0.92〜1.07（上限 1.2）。地面が閾値を超えないよう光の強さを抑え（指示値×0.78）、水滴は空中の数に応じて不透明度を下げる。画面全体のフラッシュなし。
- **画質**: `?q=low|mid|high` で固定（自動調整停止）。指定なしは mid で開始、1秒ごとの FPS で 3 秒平均 < 50 なら下げ、10 秒間 ≥ 58 なら上げる（クールダウンあり、起動直後・非表示中は除外、クライマックス中は上げない）。DPR 1/1.5/2、影 なし/1024/2048、Bloom なし/半解像度/通常、水滴 1200/3500/8000、蒸気 80/180/400、地形分割 48/80/128、水面の波 1/2/3 層。粒子はプール（リングバッファ）で再利用。
- **監視**: `window.__ready`（初期化と2フレーム描画のあと true）、`window.__errors`（three 読み込み前から error / unhandledrejection / 初期化・フレーム中の例外）。`window.__game.snapshot()` で状態を読める（画面には何も出さない）。
- **`?autotest`**: 対象ポンプの画面位置に本物の PointerEvent（touch と mouse を交互）を送る。通常と同じ当たり判定・充填・噴射・状態遷移を通る。1回目は 50% 付近で一度離して圧力が残ることを確かめてから押し直す。15回 → クライマックス → 余韻 → 初期状態まで進んで止まる。

## 確認結果（このクラウド環境、ヘッドレス Chromium + SwiftShader、iPad 実機ではない）

詳細は `logs/e03/test.txt`。

- `games/e03/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で実行: `__ready` = true、`__errors` = []、コンソールエラーなし。15回の噴射・3段階 → クライマックス到達 → 余韻 → 初期状態（READY、中央のポンプ）に戻るところまで確認。途中で離したときの圧力保持（p≈0.5 で離して続きから充填）も確認。
- 640x480 を **mid**（Bloom 半解像度・影あり）で同様に実行し、エラーなし・クライマックス到達。
- スクリーンショット: `shot-1.jpg`（序盤、横）、`shot-2.jpg`（中盤、第2段階の噴射と虹、横）、`shot-3.jpg`（クライマックス 24 秒付近、全5本同時噴射＋大きな虹、横）、`shot-3-portrait.jpg`（同、縦）。最大の光の瞬間でも空の色・5本の水柱の輪郭・虹・温泉の地形が見えて白飛びしていない（low と mid/Bloom 両方で確認）。操作対象のポンプは横で (512, 457)、縦で (384, 625) と画面中央 30% の範囲内。クライマックスの水柱・虹・ポンプは縦横とも画面端で切れていない。
- サムネイル `site/thumbs/e03.jpg`: mid 640x480 のクライマックス画面（文字なし）。
- 禁止語の grep: 該当なし。外部 URL なし（gf-playlog.js の送信先はテストではローカルで 204 を返すようにした）。

## 未解決・未検証の点

- iPad 実機・iPhone 実機・Safari での動作、FPS、自動画質調整の切り替わりは未検証（ソフトウェア描画のみ）。音もヘッドレスでは鳴らしていない（自動再生制限下でも進行が止まらないことのみ確認）。
- high 画質はスクリーンショットで確認していない（コード上は mid と同じ経路で、粒子数・影・Bloom 解像度だけが違う）。
- 縦画面のクライマックスは横幅で距離が決まるため、水柱が画面の中で小さめ（下 1/4 が地面）。
- カメラの俯角は空を見せるため指示文より浅い（14° / 11°）。
- 水柱の芯は CPU 側の弾道粒子と見た目を合わせているだけで、流体計算はしていない。low では水滴が少なく、粒の一つ一つが見える。
- 雲は空のシェーダー内の fbm で、立体的な雲のメッシュはない。
