# E04 実装指示文：おひさま ランタンのメリーゴーラウンド

## 1. ゲームの狙い

5歳の女の子が、丘の上の庭園にある巨大な真鍮製の回転装飾に、自分の指で一灯ずつガラスランタンを取り付け、世界に一つだけの光のメリーゴーラウンドを完成させるゲームを制作する。

- **夢×写実：** 本物の真鍮の反射、厚みのあるガラス、炎のゆらぎを写実的に再現しながら、現実には存在しない巨大で美しい光の工芸品を作り上げる。
- **高揚感：** 一灯ずつ増えるランタンの輝きが、やがて庭園全体を黄金色に照らす壮大な光の舞踏会へと発展する。
- **爽快感：** ランタンをフックに引っ掛けた瞬間の「カチッ」という感触と、小さな指の操作によって巨大な装置が動き出す反応を楽しませる。

本作の最重要体験は、**自分が取り付けた一つのランタンによって、大きな世界が動き始めること**である。

完成した装置を眺めるだけのゲームにしない。取り付ける、はまる、点灯する、回転するという一連の因果関係を、毎回はっきりと体感できるようにする。

光を空へ送り出すゲームではなく、実体のある工芸品を少しずつ組み立てて完成させるゲームとする。

## 2. 絵から借りる光と色

### 2.1 美術の基本方針

マックスフィールド・パリッシュの作品に見られる、深い群青色の空と黄金色の人工光の対比、石造建築の重量感、発光するランタンの幻想性を参考にする。

元の作品の構図、人物、建築物の配置、絵柄は再現しない。

現実と想像が溶け合う写実的な3D空間とし、長編ファンタジー映画のように、光によって世界が変化する驚きと祝祭感を表現する。

実写映画のセットを撮影したような素材感を目標とする。平面的なイラスト調、低ポリゴン調、プラスチック製玩具のような質感にはしない。

### 2.2 時間帯と空の変化

ゲームの進行に伴い、黄金色の夕暮れから、鮮やかな群青色のブルーアワーへ移行する。

| 項目 | 第1段階 | 第2段階 | 第3段階 | 第4段階 |
|---|---|---|---|---|
| 天頂の空 | `#416BB2` | `#3159A2` | `#23478F` | `#244695` |
| 地平線 | `#FFD69A` | `#FFC58A` | `#B5B7E7` | `#A9B9EF` |
| 雲の受光面 | `#FFE5BB` | `#FFD5A7` | `#EAC4CF` | `#D6D7F5` |
| 環境光強度 | 1.3 | 1.2 | 1.1 | 1.1 |
| 太陽光強度 | 2.0 | 1.5 | 0.9 | 0.5 |
| 月光強度 | 0.2 | 0.4 | 0.7 | 1.0 |

数値はThree.jsのライティングを調整する際の初期値であり、最終的には実際のレンダリング結果を見て調整すること。

時間帯が進んでも、庭園の石畳、植物、装置の金属部分、空いているフックが常に識別できる露出を維持する。

真夜中や漆黒の背景には移行しない。

### 2.3 光源の設計

- 夕日の色温度：3500〜4200K。色の目安は `#FFD3A0`。
- 月光の色温度：7500〜9000K。色の目安は `#B9D5FF`。
- ランタン内部の炎：1800〜2400K。色の目安は `#FFB347`。
- 炎の中心部：`#FFF0BC`。
- 天空からの環境光：`#A9C7FF`。
- 地面からの反射光：`#B8A17B`。

ランタンのガラスには赤、琥珀、桃色、青、水色、緑、紫などを使用する。ただし、内部の炎は共通して温かみのある金色とし、色付きガラスを透過することで周囲に異なる色の光が広がる構造にする。

### 2.4 霧・露出・ブルーム

以下を初期設定の目安とする。

| 設定 | 通常時 | クライマックス |
|---|---:|---:|
| トーンマッピング | ACESFilmic | ACESFilmic |
| Exposure | 1.05〜1.2 | 1.05〜1.25 |
| Bloom strength | 0.35〜0.6 | 0.85〜1.1 |
| Bloom threshold | 0.9 | 0.85 |
| Bloom radius | 0.35 | 0.55 |
| Fog near | 25m | 25m |
| Fog far | 110m | 110m |

ブルーム強度は最大1.2、しきい値は0.8以上とする。

ランタンの形状、金属の輪郭、ガラスの色、群青色の空を、最も光が増した瞬間でも確認できること。画面全体を白く覆う演出は禁止する。

霧は遠景の丘と樹木に奥行きを与えるために使用し、手前の装置や操作対象にはほとんど影響させない。

## 3. 舞台と登場するもの

### 3.1 丘の上の庭園

見晴らしのよい丘の上に、円形の石造庭園をプロシージャル生成する。

中央には巨大な回転装飾があり、その周囲を石畳、花壇、浅い水盤、白い石の手すりが囲む。遠くにはなだらかな丘と樹木が連なり、広い空が見える。

| オブジェクト | 大きさの目安 | 表現方法 |
|---|---|---|
| 円形庭園 | 直径24m | 石畳、円形の段差 |
| 回転装飾 | 高さ4.5m、直径6m | 真鍮、ガラス、歯車 |
| 水盤 | 幅0.8〜1.2m | 装置周囲の円弧状の水路 |
| 花壇 | 高さ0.3〜0.6m | 白、桃色、紫の花 |
| 石の手すり | 高さ0.9m | 石柱と装飾的な笠石 |
| 遠景の丘 | 距離40〜100m | 起伏のある低負荷メッシュ |
| 雲 | 距離60m以上 | 手続き的な形状と色の変化 |

庭園は単なる背景ではなく、ランタンが増えることで石畳や水面に光が映り込み、次第に姿を変えていく舞台とする。

人物、動物、乗用の遊具は登場させない。本作のメリーゴーラウンドは人が乗るものではなく、鑑賞用の巨大な回転工芸品である。

### 3.2 巨大な回転装飾

本指示では、4つの回転輪に各6個、合計24個のランタンを取り付ける構成を採用する。

中央の真鍮製支柱を軸として、高さと直径の異なる4つの水平な輪を設ける。

- 最下段：直径6.0m。
- 第2段：直径5.0m。
- 第3段：直径4.0m。
- 最上段：直径2.8m。
- 各輪に6個の吊り下げ式フックを等間隔に配置する。
- 支柱の頂上には、太陽をかたどった金属と琥珀色ガラスの装飾を設ける。

支柱、接合部、歯車、軸受け、ボルト、装飾的な金属棒を組み合わせ、実際に製造できそうな機械構造にする。

輪が空中に浮いているような構造にはせず、中央支柱との接続を視覚的に理解できるようにする。

下部の台座には、大きな歯車と小さな歯車を設ける。ランタンを取り付けると歯車がかみ合って回り、輪が動く仕組みを目で楽しめるようにする。

### 3.3 真鍮の質感

`MeshStandardMaterial` または `MeshPhysicalMaterial` を使用する。

- Base color：`#C9A35C`
- Metalness：0.85〜1.0
- Roughness：0.22〜0.38
- 微細な研磨傷と加工痕を手続き的なテクスチャで表現する。
- エッジ部分にはわずかな面取りを施し、光が細い線状に反射するようにする。
- 接合部分や溝には控えめな経年変化を加える。

単色の黄色い金属ではなく、見る角度によって空の青、ランタンの金、庭園の色が映り込む素材とする。

環境反射には、手続き的に作成した空と光源をPMREMで処理した環境マップを使用する。

### 3.4 ガラスランタン

ランタンそのものを、本作で最も丁寧に造形するオブジェクトとする。

高さ0.45〜0.65m程度とし、以下の部品で構成する。

- 真鍮製の吊り下げリング。
- 金属製の上蓋と底部。
- ガラスを支える細い金属フレーム。
- 厚みのある透明または色付きガラス。
- 内部のろうそくと小さな炎。
- 炎の光を受けて反射する内部金属面。

ランタンには六角形、円筒形、球形、しずく形、花形など、複数の形状を用意する。ただし、形状によるフックの適合判定は行わない。すべてのランタンを同じ操作で取り付けられる。

ガラスの設定目安：

| パラメータ | 値 |
|---|---|
| Transmission | 0.85〜0.98 |
| Roughness | 0.06〜0.16 |
| IOR | 1.45〜1.52 |
| Thickness | 0.015〜0.035m |
| Metalness | 0 |
| Attenuation distance | 0.3〜1.0m |

ガラスには面ごとの反射、縁の屈折、微細な法線のゆらぎを加える。

炎は透明メッシュとシェーダーを組み合わせて生成する。炎の中心部、外周、上端を区別し、複数の周波数を持つノイズで自然にゆらがせる。

炎を大きな発光球で代用しない。火の粒子が外部へ飛び散る表現も不要である。

### 3.5 石畳・植物・雲・水面

**石畳**

石材ごとにわずかな色差、粗さ、凹凸を与える。規則的な格子状の床ではなく、放射状または円弧状に石が敷かれた庭園とする。

**植物**

葉の形状を持つ小さなメッシュをInstancedMeshで配置する。花壇には白、桃色、淡紫色の花を植え、風に合わせてわずかに揺らす。

**空と雲**

空はグラデーションシェーダーで生成する。雲は手続き的なノイズを用い、夕日の方向に金色の受光面を作る。雲の移動速度は十分に遅くする。

**水面**

水盤には、複数方向の波を合成した水面シェーダーを使用する。

- 波高：0.005〜0.025m。
- 波長：0.15〜0.6m。
- Fresnel反射を使用する。
- 水の基本色：`#537FA0`。
- 水底の石材が部分的に見える透明感を持たせる。
- ランタンが増えると、金色や赤、桃色の反射が増える。

外部の画像、HDRI、3Dモデル、テクスチャ、音声ファイルは使用しない。すべてコードによる手続き的な生成とする。

## 4. 指1本のゲームループ

### 4.1 開始時

タイトル画面やメニューを表示せず、最初から完成前の回転装飾が置かれた庭園を表示する。

装置は停止している。手前中央の石製の作業台には、最初のランタンが一つ置かれている。

そのランタンだけが小さく揺れ、金属の縁に光が走る。

ランタンに触れるとAudioContextが起動し、そのままドラッグ操作を開始できるようにする。開始のためだけの余分なタップを要求しない。

### 4.2 1回の操作の流れ

| 経過時間の目安 | プレイヤーの操作・世界の反応 |
|---|---|
| 0秒 | 作業台にランタンが現れる |
| 0〜2秒 | 対応する空のフックに金色の光が走る |
| 2〜5秒 | 指でランタンを持ち上げ、フックへ運ぶ |
| 5秒 | 吊り下げリングがフックに吸い寄せられる |
| 5.1秒 | カチッという音とともに固定される |
| 5.3秒 | 内部の炎が点灯する |
| 5.5秒 | 金属の輪と歯車が回転を始める |
| 6〜8秒 | 次の空のフックが正面に到着する |
| 8秒 | 作業台に新しいランタンが現れる |

時間は目安であり、プレイヤーを急がせない。操作していない間に制限時間が減る仕組みは作らない。

### 4.3 ドラッグの感触

ランタンに触れた瞬間、作業台からわずかに浮き上がる。指の移動にほぼ遅延なく追従し、移動方向に応じて最大5〜10度程度傾く。

指を離すときだけでなく、対応フックの十分近くに到達した時点で自動的に取り付けを開始してよい。

取り付け位置が近づくと、吊り下げリングとフックの位置・角度が自然にそろう磁力的な補助を実装する。

- ランタンのタッチ領域：最低64×64 CSS pxを目安とする。
- フックへの吸着範囲：画面上で半径45〜70 CSS px程度。
- 吸着アニメーション：120〜220ms。
- 取り付け後の揺れ：最大6度程度。
- 揺れの減衰時間：0.6〜1.0秒。

厳密な位置合わせは要求しない。幼児が大まかにフックへ運ぶだけで成立させる。

### 4.4 成功時の手ごたえ

取り付けが完了するたびに、以下の順序で反応させる。

1. 金属同士が接触する短い「カチッ」という音。
2. ランタン内部の炎が点灯する。
3. 金色の光の粒がランタンの周囲に少量広がる。
4. 取り付けた輪に沿って光が流れる。
5. 台座の歯車が回り、巨大な輪が動き始める。
6. 石畳、水面、近くのランタンに新しい光が加わる。

特に5番目の反応を重視する。小さなランタンを一つ取り付けただけで、装置全体に動きが伝わる感覚を作る。

取り付け後は、現在組み立てている輪が60度分回転し、次の空のフックが正面に移動して停止する。

すでに完成した輪は、その後も独立して回転を続ける。

### 4.5 失敗のない設計

フックから遠い位置で指を離した場合、ランタンは0.4〜0.7秒程度かけて作業台へ戻る。

ランタンが割れる、落下する、火が消える、警告音が鳴る、完成済みのランタンが外れるといった現象は一切発生させない。

操作がない場合は、以下の誘導を行う。

- 2.5秒後：作業台のランタンの金属縁に光が走る。
- 4秒後：ランタンがわずかに浮き、元の位置に戻る。
- 6秒後：空のフックに光が集まり、短く揺れる。
- 以後、同様の誘導を繰り返す。

文字、矢印、手のアイコン、操作説明のポップアップは使わない。

## 5. 盛り上がりの設計

全4段階、各6灯、合計24灯を取り付ける構成とする。

標準的なプレイ時間は3〜5分を想定するが、早く操作した場合に無意味な待ち時間を追加しない。

### 第1段階：最初の光がともる

- 取り付け数：1〜6灯。
- 主な色：金色、琥珀色、桃色。
- 完成する輪：最下段。
- 完成後の回転速度：0.7rpm。

夕日の残照が庭園を包んでいる。

一灯ずつ光が増え、最初の輪が完成すると、6灯が順番に輝いて輪全体が連続回転を始める。

### 第2段階：色とりどりの光が踊る

- 取り付け数：7〜12灯。
- 主な色：赤、青、水色、紫。
- 完成する輪：第2段。
- 完成後の回転速度：反対方向に1.1rpm。

空が深い青へ変わり、ランタンの色がより鮮明に見えるようになる。

二つの輪が異なる方向へ回転し、ガラスを通した光の色が水面に映る。

### 第3段階：庭園全体が輝き始める

- 取り付け数：13〜18灯。
- 主な色：緑、白、金、紫。
- 完成する輪：第3段。
- 完成後の回転速度：1.6rpm。

月が姿を現す。ランタンの光が花壇、石柱、石畳へ届き、庭園全体の印象が変化する。

音にも高音域のベルや穏やかな和音を加える。

### 第4段階：黄金の光の舞踏会

- 取り付け数：19〜24灯。
- 主な色：虹色のガラスと黄金色。
- 完成する輪：最上段。
- 完成後の回転速度：反対方向に2.0rpm。

最後のランタンは、他より少し大きく、細かな金属装飾が施された特別な琥珀色のランタンとする。

操作方法は変えず、これまでと同じドラッグ操作で取り付ける。

### 5.1 クライマックス：大きな光の解放

最後のランタンを取り付けた瞬間から、約15〜20秒間の特別演出を開始する。

- 0〜2秒：最上段の輪が動き始める。
- 2〜5秒：24灯のランタンが、最下段から順番に輝きを増す。
- 5〜8秒：真鍮の支柱に沿って金色の光が上昇する。
- 8〜11秒：頂上の太陽形装飾が点灯し、放射状の装飾がゆっくり展開する。
- 11〜15秒：4つの輪が異なる速度・方向で回転し、庭園全体に金色と虹色の光が広がる。
- 15〜20秒：回転速度と音楽が安定し、完成した装置の美しさを楽しむ時間へ移行する。

光の解放は、画面全体の露出を上げることではなく、**発光する範囲、光の色、反射する物体の数、装置の動きが増えること**で表現する。

頂上の太陽形装飾が点灯しても、輪郭や内部構造が識別できる状態を維持する。

### 5.2 余韻とフリープレイ

クライマックス後は、完成した装置で自由に遊べる状態に移行する。

取り付け済みのランタンをタップすると、そのランタンの光が一時的に強まり、短いベル音が鳴る。

台座の真鍮製ハンドルをタップすると、4つの輪が滑らかに加速する。最高速度は通常時の1.5倍程度とし、数秒かけて元の速度へ戻す。

完成済みの装置を勝手に消去しない。

作業台の横に再組み立て用の円形の真鍮製ダイヤルを出現させ、1秒程度触れ続けると、ランタンが順番に作業台へ戻って最初の状態から遊べるようにする。

## 6. カメラ

### 6.1 基本構図

カメラは回転させない。回転するのは装置だけとする。

PerspectiveCameraを使用し、回転装飾の中心軸と中央付近の高さを注視する。

- FOV：38〜45度。
- 装置からの距離：10〜16mを初期値とする。
- 見下ろし角度：8〜15度。
- ロール角：常に0度。
- Near：0.1m。
- Far：200m。

回転装飾の中心軸を画面中央の縦線に維持する。

プレイヤーが取り付けるフックは、輪を回転させることによって装置の正面に運ぶ。カメラがフックを追いかける方式にはしない。

### 6.2 操作対象の配置

装置の中心軸と操作対象が同時に見えることを最優先とする。

現在のフックと作業台のランタンは、原則として画面中央付近の縦方向に並べる。

画面左上や右下など、装置から大きく離れた場所に次のランタンを出現させない。

目標フックを画面幅の中央40％以内に、操作前のランタンを中央下部に配置する。ドラッグ中を除き、操作対象を端へ移動させない。

### 6.3 縦向き・横向きへの対応

画面比率に合わせて、装置、作業台、操作対象の境界を画面上へ投影し、必要なカメラ距離を計算する。

画面の上下左右に最低8％程度の安全余白を確保する。

- 横向き：庭園の左右の広がりを見せる。
- 縦向き：装置の高さと4つの輪を見せる。
- 狭い画面：背景の余白より、装置と操作対象の視認性を優先する。

クライマックスでは展開後の頂上装飾も含めて収まるよう、必要なら演出開始前にカメラを少し引く。

カメラ位置の変更は0.8〜1.5秒程度かけて補間する。ドラッグ中はカメラを固定する。

カメラシェイク、急なズーム、周回移動、視点の回転は禁止する。

## 7. 操作

iPad Safari、iPhone Safari、PCブラウザのタッチおよびマウス操作に対応する。

入力はPointer Eventsに統一する。

- `pointerdown`：操作対象を取得する。
- `pointermove`：ランタンを移動させる。
- `pointerup`：取り付け判定または作業台への復帰を行う。
- `pointercancel`：操作状態を安全に解除する。
- `setPointerCapture`：指が対象から外れてもドラッグを維持する。

同時に受け付けるポインターは1本だけとし、2本目以降は無視する。

ドラッグ中のランタンは、カメラに対向する操作平面上を移動させ、フックに近づいたときに実際の3D取り付け位置へ補間する。

ゲーム領域では以下を抑止する。

- ピンチズーム。
- ダブルタップズーム。
- ページスクロール。
- オーバースクロール。
- 長押しメニュー。
- テキスト選択。
- 画像などの標準ドラッグ動作。

`touch-action: none`、`user-select: none`、適切なviewport設定などを使用する。

画面回転やアプリ切り替えによってドラッグ状態が残り続けないようにすること。

## 8. 音

WebAudio APIを使用し、すべての音を手続き的に合成する。

最初のタップでAudioContextを生成または再開する。

### 8.1 操作音

| 操作 | 音の設計 |
|---|---|
| ランタンを持つ | 小さなガラスの接触音 |
| フックへの吸着 | 短い金属音 |
| 固定完了 | 歯切れのよい「カチッ」 |
| 点灯 | 澄んだベル音 |
| 輪の回転 | 低音量の歯車と機械音 |
| 段階の完成 | 複数のベルによる上昇音 |
| 全灯完成 | 広がりのある長調の和音 |

金属音は複数の非整数倍周波数のサイン波と短いノイズを組み合わせて生成する。

ガラス音には高周波成分と自然な減衰を与える。耳に刺さる高音や突然の大音量は避ける。

### 8.2 段階ごとの成功音

- 第1段階：Cメジャーペンタトニックの単音。
- 第2段階：単音に3度または5度を追加する。
- 第3段階：アルペジオと三和音を組み合わせる。
- 第4段階：高音のベルと低音の和音を重ねる。

最後は4つの輪それぞれに対応する音が一つの調和した和音へ収束する構成とする。

### 8.3 環境音

控えめな風の音、水盤の水音、遠くから聞こえるような持続音を組み合わせる。

BGMは操作音を邪魔しない音量にする。マスター音量は0.3〜0.45程度を初期値とし、必要に応じてコンプレッサーでピークを抑える。

外したときの警告音、不正解音、カウントダウン音は実装しない。

## 9. 画面の文字

ゲーム画面には文字、数字、タイトル、スコア、タイマー、操作説明、ボタンラベルを一切表示しない。

進行状況は、空いているフックの数、取り付けられたランタンの数、回転している輪の数によって自然に理解できるようにする。

一般的なゲームUIを重ねるのではなく、ゲームの機能を実体のある3Dオブジェクトに持たせる。

## 10. 画質の自動調整

2020年モデル相当のiPad ProのSafariで、安定して50fps以上を維持することを目標とする。

起動時に短時間の描画性能測定を行い、実行中もフレーム時間を監視する。

| 項目 | high | mid | low |
|---|---:|---:|---:|
| 最大ピクセル比 | 1.75 | 1.25 | 1.0 |
| シャドウ解像度 | 2048 | 1024 | 512または無効 |
| 水面反射 | 縮小解像度の実反射 | 環境反射＋疑似反射 | 疑似反射 |
| Bloom | 有効 | 低解像度 | 無効または疑似発光 |
| ガラス | Transmission | 簡略化したTransmission | 透明＋Fresnel反射 |
| 最大パーティクル数 | 400 | 180 | 60 |
| 動的な補助光源 | 4 | 2 | 1 |

24灯すべてに影を生成するPointLightを配置しない。

ランタン自体の発光はEmissive Materialで表現し、石畳への光は加算合成の光斑や少数の代表光源で補う。

ガラスの透過描画は負荷が高くなりやすいため、FPS低下時には優先的に簡略化する。

植物、石材、フック、歯車などの反復形状にはInstancedMeshやジオメトリの共有を活用する。

画質切替の目安：

- 直近3秒間の平均FPSが48未満：1段階下げる。
- 直近12秒間の平均FPSが58以上：1段階上げることを検討する。
- 切替後8秒間：再切替を抑制する。
- ドラッグ中：原則として切り替えない。

URLパラメータ `?q=low`、`?q=mid`、`?q=high` で画質を強制指定できるようにする。強制指定時は自動切替を停止する。

画質を落としても、ランタンの形状、点灯、フックへの吸着、輪の回転、クライマックスの内容は維持する。

## 11. 技術構成

### 11.1 ファイル構成

ゲーム本体は以下の1ファイルに実装する。

`site/games/e04/index.html`

HTML、CSS、JavaScript、シェーダー、手続き的なテクスチャ生成、音声合成処理をすべてこのファイルにまとめる。

Three.jsはリポジトリに同梱済みのものを使用する。

importmapの対応関係：

| インポート名 | 相対パス |
|---|---|
| `three` | `../../vendor/three/build/three.module.min.js` |
| `three/addons/` | `../../vendor/three/examples/jsm/` |

CDN、外部API、外部素材、外部フォント、新規の外部ライブラリは使用しない。

`<head>` 内に以下を含める。

`<meta name="robots" content="noindex">`

`</body>` の直前に以下を含める。

`<script src="../../gf-playlog.js" defer></script>`

### 11.2 ゲーム状態管理

内部状態は明確なステートマシンで管理する。

| 状態 | 内容 |
|---|---|
| INIT | 初期化 |
| IDLE | ランタンへの入力待ち |
| DRAGGING | ランタンの移動中 |
| ATTACHING | フックへの吸着・固定 |
| IGNITING | 点灯演出 |
| ROTATING | 輪の回転と次のフックへの移動 |
| STAGE_COMPLETE | 段階完成演出 |
| FINALE | クライマックス |
| FREE_PLAY | 完成後の自由操作 |
| RESETTING | 再組み立て準備 |

連続タップによる二重取り付け、同一フックへの重複登録、アニメーションの競合を防止する。

装置の回転、炎のゆらぎ、パーティクル、音のタイミングはフレームレートに依存しない時間ベースの処理とする。

### 11.3 準備完了とエラー監視

以下を用意する。

- `window.__ready`：初期値はfalse。必要なオブジェクトの生成と初回レンダリングが完了した時点でtrueにする。
- `window.__errors`：初期値は空配列。実行時エラーや未処理のPromise rejectionなどを記録する。

初期化に失敗した場合に、実際には遊べない状態で準備完了を通知しない。

### 11.4 自動プレイ

`?autotest` を付与した場合は、自動プレイモードを起動する。

自動プレイでは、ランタンの取得、移動、フックへの吸着、固定、点灯、回転を順番に実行する。

通常プレイと同じ取り付け処理および状態遷移を使用し、内部の成功数だけを直接書き換える方式にはしない。

24灯すべてを取り付け、全4段階を経てクライマックスとフリープレイまで到達させる。

自動テスト用の文字や数値を画面に表示しない。

### 11.5 禁止事項

気持ち悪い生き物、おばけ、怪物、不穏な造形、お姫様、人物、実在のキャラクター、ブランド要素、既存作品を直接連想させる意匠を登場させない。

暗く重い世界、点滅を繰り返す強い光、画面全体を覆う発光、急激なカメラ移動を禁止する。

別紙の禁止語は、ゲーム画面、HTML、CSS、JavaScript、コードコメント、変数名、実装時に作成する説明文のいずれにも使用しない。表記を変更したものも使用禁止とする。

## 13. 実装時の優先順位

実装リソースが限られる場合は、次の優先順位で品質を確保する。

1. ランタンをフックに取り付ける操作の気持ちよさ。
2. 真鍮・ガラス・炎の写実的な素材感。
3. 一灯の追加によって巨大な装置が動く因果関係。
4. 完成に近づくにつれて増していく光と色の美しさ。
5. 4つの回転輪による壮大なクライマックス。
6. 庭園、水面、花壇、遠景の細部。

背景の造形に時間を費やしすぎて、ランタンの造形や取り付け操作が簡素にならないようにする。

本作の完成基準は、5歳の子どもが説明なしで遊び始め、自分で取り付けたランタンが光り、巨大な装置が動くことに喜びを感じ、次のランタンも自分で取り付けたくなることである。
