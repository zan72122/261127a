# E15 たきのうえの きょだいなビーだまこうぼう — 実装メモ

実装: `site/games/e15/index.html`（HTML + CSS + JS を1ファイル。Three.js 同梱版を importmap で読み込み。CDN・外部画像・外部モデル・音声ファイルなし。テクスチャ・地形・音はすべてプログラム生成）

## 実装の要点

- **舞台**: 岩の柱の上に張り出した石のテラス（石畳は canvas で石ごとの色差・目地・角の摩耗・法線を生成）。奥に幅24・高さ約60の滝（3層の半透明シート、流速の違う下向きノイズ、Fresnel、空色の透過、太陽の筋、水煙の GPU パーティクル、霧の塊）、滝の左右に地層のある崖（頂点ノイズ変位＋頂点色、上は草地）、崖の上と左手前の岩の上の家々・列柱テラス（岩の表面に raycast で配置）、遠景の山（空気遠近は Fog）、雲、谷底の水面。水しぶきを通る光の筋（加算の板）と、装置のまわりを漂う光の粒。
- **からくり装置（すべてプロシージャル）**:
  - レールは CatmullRomCurve3 の共通曲線から生成し、玉の位置も同じ曲線（弧長サンプル）から求めるので浮き・埋まりなし。経路 A（木の二本レール・木目は長手方向）、B（真鍮・2.25周の螺旋＋空中に張り出した二本レール）、C（真鍮・観覧輪へ → 頂上から上段レール → 左をジグザグに下る）。枕木・支柱は結合して1メッシュ化。
  - 歯車は ExtrudeGeometry で実際の歯を持ち、歯数比・逆回転・噛み合いの位相を式で合わせた4組（壁の大歯車40/12/18、木レール脇の小歯車10/14、螺旋の20/12、観覧輪の軸16/28/12）＋昇降機のスプロケット。
  - 鐘（旋盤形状＋舌、減衰振動）、シーソー、水車（バルブが開くと水が流れて回る）、バケット式昇降機（12個、上りのバケットにビーだま）、観覧輪（ガラスのゴンドラ8個、外周のランプ）、分岐ゲート、ガラスの光の塔（進捗で下から満ちる光）、透明な受け皿（到着した玉が実際に積み上がる）。
  - ビーだま: 透明な外殻＋内部の3枚のねじれた色ガラス（別メッシュ、一緒に回転）。赤・桃・青・水色・緑・黄・紫、24個目は虹色（high/mid は iridescence）。high は全玉、mid は操作対象の玉だけ MeshPhysicalMaterial の transmission、low は視線角で不透明度が変わる簡易ガラス。回転角＝移動距離/半径。
- **遊び（指1本）**: 中央手前の受け台のビーだまをタップ、または投入口の方へ少しドラッグ（画面上で投入口までの55%で吸着）。当たり判定は半径 max(72px, 短辺の17%)、最初の1回は画面のどこを触っても始まる。玉は投入口に吸い込まれ、管を通ってレールへ。仕掛けの発動地点を経路上に定義し、玉が通過した瞬間に機械の動き・光・音を同時に出す。新しい仕掛けが初めて動くときは、玉から仕掛けへ金色の光が飛ぶ。
  - 第1段階（1〜6個、木レール、朝）: 鐘 → シーソー → 小歯車 → 2つ目の鐘 → 水車 → 6個目で大歯車3枚が回り真鍮が金色に光る。
  - 第2段階（7〜12、昼）: ゲートが切り替わり螺旋へ。周回ごとに歯車へ回転が伝わる。空中レールの鐘3つが順に現れ、11個目で連続して鳴る、12個目で昇降機が動き出す。
  - 第3段階（13〜18、黄金の午後）: 玉が観覧輪のゴンドラに乗って上がり、頂上で上段レールへ送り出される。上段の鐘3つ、塔の鐘、18個目で鐘が順に鳴り、レールに金色の光が走り、滝の水煙に虹が現れる。
  - 第4段階（19〜24、夕暮れ・暗くしない）: 受け皿の玉が別の経路にも送り出され、複数の色の玉が同時に走る（速度は第1段階の1.35〜1.4倍）。23個目の到着後に虹色の玉。
  - **クライマックス（約18.5秒）**: 虹色の玉が観覧輪経由で全体を通過（レールに虹色の光が玉を追って走る）→ 受け皿の8個が3経路へ → 歯車・観覧輪・昇降機・水車が調和した速度へ → 各装置から塔へ色とりどりの光が集まり塔が満ちる → 塔から光の帯が装置と水煙へ伸び、水煙に大きな虹 → 塔の大きな鐘と全部の鐘 → 余韻9秒で減速 → フリープレイ（新しい玉が受け台に出て、C→B→A の順に経路を変え、受け皿の玉も2個ずつ一緒に走る）。終了画面・強制遷移なし。
  - 無操作2秒で玉の表面を光の筋が横切り、4秒で玉が揺れ投入口の縁を光が回る。失敗・減点・警告なし。関係ない場所のタップ、2本目以降の指、連打は無害。
- **白飛び対策（前回の反省）**: ACESFilmic、基準露出0.86（クライマックスでも最大0.89）。ブルームは しきい値1.0・強さ通常0.28〜最大0.55・半径0.3、ブルームの前で HDR を1.7にクランプ（重なった光が画面に広がらない）。塔の光・光粒・光の帯の明るさを抑え、水煙の粒は数が多い画質ほど1粒を淡く。クライマックス最大の光の瞬間のスクリーンショットで、歯車・観覧輪・玉の色・空の色が識別できることを確認。
- **カメラ**: 方位20°・俯角10.5°固定、ロール0、玉を追わない。主要点（観覧輪の外周、塔の頂上、昇降機、受け皿、水車、空中レールなど）が上下左右10%（縦画面は8%）の余白内に入り、かつ操作対象の玉が中央付近に来る注視点と距離を数値探索（縦横どちらも）。クライマックスは光の塔を中央に置く構図へ約2.5秒かけて移動。
- **入力**: Pointer Events、最初の pointerId のみ、setPointerCapture、pointercancel・blur・タブ非表示で解除。touch-action・選択・長押し・ダブルタップ・ピンチ・スクロール抑止。
- **音**: WebAudio のみ（最初のタップで AudioContext を作成・resume、失敗しても進行）。コンプレッサー＋マスターゲイン＋合成リバーブ。触れる音、吸い込み、転がり（木＝低い帯域ノイズ、真鍮＝高い帯域ノイズ、枕木ごとの接触音）、鐘（倍音＋減衰）、歯車のクリック（回転に同期）、昇降機の周期音、受け皿のガラス音（段階ごとに単音→2音→3和音→アルペジオ）、滝の連続ノイズ、控えめなパッド、クライマックスの上昇アルペジオと持続和音・大きな鐘。C メジャー系ペンタトニック。
- **画質**: `?q=low|mid|high` で固定（自動切替なし）。指定なしは mid から開始し、45fps 未満が2.5秒続くと1段下げ、57fps 以上が9秒続くと上げる（切替後10〜15秒待機）。high: DPR上限1.75・影2048・ブルーム・水煙520・全玉透過、mid: 1.25・影1024・ブルーム・260・操作対象のみ透過、low: 1.0・影なし（接地影の板）・ブルームなし・100・簡易ガラス。
- **状態**: READY / WAITING / LAUNCH / ROLLING / MECHANISM / ARRIVE / STAGE_UP / CLIMAX / AFTERGLOW、フリープレイは free フラグ。`window.__ready`、`window.__errors`（Three.js 読み込み前に error / unhandledrejection を捕捉）、`window.__test`。
- `?autotest`: 通常の pointerdown / move / up を合成し、タップ・ドラッグ・短いドラッグを順に使って24個を投入（途中で関係ない場所のタップ1回、2本目の指1回）→ 段階移行3回 → クライマックス → 余韻 → フリープレイで2個 → finished。時間は1.6倍速（各仕掛けの発動・到着処理は省略しない）。確認用に `?pre=N&dev`（N個到着済みから開始）、`?nobloom`、`?dbg`。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright ヘッドレス Chromium（`--use-angle=swiftshader --enable-unsafe-swiftshader`）で `games/e15/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で全工程実行。結果は `logs/e15/test.txt`、スクリプトは `logs/e15/run-test.js`。
- **横・縦とも PASS（ALL PASS）**: `__ready === true`、`__errors` 空、コンソールエラーなし、24/24 到着、段階移行3回、仕掛けの初回作動11件、クライマックス（ピーク到達）→ 余韻 → フリープレイ（2個到着）→ finished。操作対象の静止位置は画面中心から NDC 横0.045/縦0.061（横画面）、0.072/0.108（縦画面）、クライマックス中の光の塔は NDC 0.06 以内。重要な点（観覧輪・塔の頂上・昇降機・受け皿・受け台）が画面外に出たフレーム 0。2本目の指を無視1回・関係ない場所のタップ1回を記録。所要 横202秒・縦206秒（SwiftShader で約5fps）。
- 追加の短縮確認: `q=mid`・`q=high`（横）と画質指定なし（縦、自動で mid→low に下がることを確認）で最初の数個まで PASS（test.txt 末尾）。
- スクリーンショット: `shot-1.jpg`（序盤・待機）、`shot-2.jpg`（中盤・観覧輪経路を走行中）、`shot-3.jpg`（クライマックス約13秒＝最大の光）、`p-shot-1〜3.jpg`（縦）。すべて 300KB 以下の JPEG。クライマックスでも白飛びせず、歯車・観覧輪・玉・空の色・虹が見え、塔は縦横とも中央、観覧輪は見切れていない。
- サムネイル: `site/thumbs/e15.jpg`（クライマックス約13秒、640x480、約62KB、文字なし）。
- 禁止語（ひらがな・カタカナ表記を含む）が `site/games/e15/` と `logs/e15/` にないことを grep で確認。

## 未解決・注意点

- iPad Safari 実機での動作・FPS・タッチの感触・音は未確認（SwiftShader は CPU 描画のため性能の指標にならない。自動テストでは発音そのものは検証していない）。
- ドローコールは low で約135、mid/high で約214（指示文の目標 low 70 / mid 100 / high 150 を超えている）。静的な部品は結合済みだが、歯車・鐘・レール・玉などは個別メッシュ。実機で重い場合は自動調整で下がる。
- 自動テストのスクリーンショットは low 画質（ブルーム・影・透過なし）。サムネイルも low 画質で撮影（high/mid はトーンマッピングとブルームの分だけ虹・光の帯がやや淡い。加算演出に補正係数をかけて差を縮めている）。
- 指示文との差: 霧の範囲は 60〜330（滝と崖を装置の約8倍遠くに置いたため。指示文の値は装置付近の尺度）。基準露出0.86（three の ACES の内部係数を考慮）、ブルームのしきい値1.0・最大0.55。人物・動物・乗りものは出していない。崖の上の家々は簡略な形。
- 観覧輪を通る経路 C はゴンドラ待ちと乗っている時間の分だけ A・B より長く、指示文の目安（8〜9秒）より長めになる可能性がある（実時間での計測は未実施）。
