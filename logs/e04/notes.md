# E04 おひさま ランタンのメリーゴーラウンド — 実装メモ

実装: `site/games/e04/index.html`（HTML＋CSS＋JS の1ファイル。Three.js は同梱版を importmap で読み込み。CDN・外部画像・モデル・音声ファイルなし。テクスチャ・形・音はすべてコードで生成）

## 実装の要点

- **舞台**: 丘の上の円形庭園（直径24m）。放射状・円弧状の石畳（シェーダーで石ごとに色差・目地・粗さを生成）、装置の台座まわりの段、前に切れ目のある円弧状の水路（縁石つき）、6つの花壇（葉と白・桃・淡紫の花を InstancedMesh、風でわずかに揺れる）、白い石の手すり（バラスター190本＋石柱）、作業台と再組み立て用ダイヤルの石柱。外側は斜面と遠景の丘（距離40〜100m）、木々（Instanced）。霧 25〜110m。
- **回転装飾**（主役）: 石の台座＋真鍮のドラム、上に大きな冠歯車（48歯）と小歯車3つ（16歯、逆回転、うち1つにハンドル）。中央の真鍮支柱に 4つの輪（直径 6.0 / 5.0 / 4.0 / 2.8m、高さ 1.6〜3.85m）。各輪はハブ・スリーブ・下のカラー・スポーク6本・斜めの支柱6本・飾り輪・玉飾りで支柱につながる（浮いていない）。各輪6個のフック（ブラケット＋J字フック）。頂上に太陽形装飾（琥珀ガラスのレンズ、真鍮スポーク、12本の光条。クライマックスで折りたたみ状態から開く）。
- **真鍮**: MeshPhysicalMaterial（`#C9A35C`, metalness 0.93, roughness 0.34 × 研磨傷の roughnessMap, 色むら・経年の斑点 map）。環境反射は手続き的な空＋地面＋ランタンの光の帯を PMREM で処理（空の色とランタン数が変わると更新）。
- **ランタン**（24個）: 吊り下げリング、上蓋、ガラスを支えるフレーム、底、ろうそく、炎。形は六角・円筒＋ドーム・球（子午線の枠）・しずく（チューブの枠）・花形（8弁、曲面の枠）。最後の1個は 1.22 倍の花形で、冠・飾り棒・下の飾りがついた琥珀色の特別なランタン。ガラスは mid/high で Transmission（0.93, IOR 1.5, thickness 0.025, attenuation 0.5m）、low は透明＋クリアコートの反射。炎はシェーダー（核・外周・根元の青を区別し、複数周波数で揺らぐ、加算合成）。ガラスの色を通した光を、石畳・花・葉・芝（マテリアルに注入した 24灯分の軽い光源計算）と水面（反射の映り込み）に届ける。影つき PointLight は使わず、輪ごとの代表点光源（high 4 / mid 2 / low 1）で真鍮のハイライトを作る。
- **水面**: 4方向の波（波高 0.004〜0.01m、波長 0.16〜0.55m）、Fresnel、空の反射、各ランタンの映り込み、水底の石。
- **操作**（Pointer Events、1本指のみ、setPointerCapture、pointercancel／blur／画面回転／タブ切替で安全に解除）: 作業台のランタンに触れると浮き上がり、カメラに向いた平面上で指にほぼ遅延なく追従、移動方向に最大約8.6度傾く。フックの近く（画面上の半径 = 短辺の7.5%、45〜70px）で自動的に吸着（0.18秒）。その手前の範囲では磁石のようにフックへ寄る。離した時点でも最後の指の位置で判定し直し、半径の1.5倍以内なら取り付け。遠くで離すと 0.55秒で作業台へ戻る（不利益なし）。タッチ判定はランタン本体の画面位置から max(48px, ランタンの高さ×0.85, 短辺の7%)。
- **取り付けの流れ**: 吸着音 → カチッ → 炎が点灯（0.35秒）→ ベル → 金の粒 → 輪に沿って光が流れる → 輪が60度回り（1.7秒、歯車も回転・歯車音）、次の空のフックが正面中央へ → 新しいランタンが作業台に現れ、金の粒が作業台からフックへ走る。吊るしたランタンは輪の加速度に応じて揺れ、減衰する（最大約6度）。
- **段階**: 6灯で輪が完成 → 6灯が順に輝き、輪が連続回転（0.7 / -1.1 / 1.6 / -2.0 rpm）、段階の音。空は指示文の4段階の色（天頂・地平線・雲・環境光・太陽・月）を灯数に合わせて連続補間。第3段階あたりで月が出る。真夜中にはしない。
- **クライマックス**（約18秒）: 0〜2秒 最上段が回り出す / 2〜5秒 24灯が下から順に輝きを増す / 5〜8秒 支柱に沿って金の光が上る / 8〜11秒 太陽形装飾が点灯し光条が開く / 11〜15秒 4つの輪が別々の速度と向きで回り、虹色の光の粒、庭への光が増える / 15〜18秒 安定してフリープレイへ。
- **白飛び対策**（前回の反省点）: ACES トーンマッピング。Exposure 1.10 → 最大 1.16。Bloom（mid/high）は strength 0.42 → 最大 0.92 前後（上限1.1）、threshold 0.9 → 0.86、radius 0.35 → 0.52。光の増加は「光る範囲・色・映り込み・動き」で表し、画面全体の露出は上げない。クライマックスでは庭への光の強さとガラスの発光を抑えめにし（最初の試作で石畳が白っぽくなったので下げた）、ランタンの色・真鍮の輪郭・太陽形装飾の構造・群青の空が見える。
- **フリープレイ**: 取り付け済みのランタンをタップ → 光が強まりベル。台座の真鍮ハンドルをタップ → 4つの輪が約1.5倍まで加速し、ゆっくり戻る。作業台の横に真鍮のダイヤルが現れ、約1秒触れ続けると、ランタンが順に作業台へ戻り、輪が元の向きへ回って最初から遊べる。完成した装置を勝手には消さない。
- **誘導**（操作がないとき、文字・矢印なし）: 2.5秒 ランタンの金属縁が光る / 4秒 小さく跳ねる / 6秒 目標フックの光が強まり、フックが揺れる。7.5秒周期で繰り返す。目標フックには常に控えめな金色の光。
- **カメラ**: 固定（回転・シェイク・周回なし）、ロール0、見下ろし約9.5度。装置の中心軸は常に画面の縦中心線上。画面比から装置（太陽形装飾の開いた光条を含む）・作業台・ダイヤルを投影し、上下左右に約8%の余白が入る距離を二分探索で計算（縦画面では FOV を最大54度まで広げる）。回転・リサイズ時は約1.1秒で補間、ドラッグ中は固定。クライマックス用に構図を変える必要がないよう、最初から開いた光条も含めて収めている。
- **音**（WebAudio、すべて合成。最初のタップで AudioContext を生成／再開。マスター 0.38＋コンプレッサー＋生成した残響）: ガラス音、吸着の金属音、カチッ、点灯のベル（第1段階 単音のペンタトニック → 第2 5度 → 第3 三和音 → 第4 高音ベル＋低い和音）、歯車音、輪の回転のうなり、段階の上昇音、クライマックスの和音、風・水・遠くの持続和音。警告音・カウントダウンなし。
- **画質**: `?q=low|mid|high` で固定（自動切替停止）。指定なしは mid で開始し、1秒ごとの FPS を見て、直近3秒平均 < 48 で1段下げ、12秒平均 ≥ 58 で1段上げ（切替後8秒とドラッグ中は切り替えない）。ピクセル比 1.0 / 1.25 / 1.75、Bloom なし / 0.55倍解像度 / 通常、影 なし / 1024 / 2048、ガラス 透明＋反射 / Transmission 半解像度 / Transmission、粒 60 / 180 / 400、点光源 1 / 2 / 4、葉と花の数。
- **状態**: INIT / IDLE / DRAGGING / ATTACHING / IGNITING / ROTATING / STAGE_COMPLETE / FINALE / FREE_PLAY / RESETTING。時間はすべて経過時間ベース（ランタンの揺れはフレーム時間が長くても破綻しないよう 8ms 刻みで計算）。
- **テスト用**: `window.__ready`（生成と2フレームの描画後に true）、`window.__errors`（error / unhandledrejection / 初期化・フレーム内の例外）。`?autotest` は本物の PointerEvent（pointerdown → pointermove → pointerup）を画面上のランタン位置からフック位置へ送るので、通常と同じ判定・状態遷移で24灯→クライマックス→フリープレイ（ハンドルとランタンのタップ）まで進む。`window.__game` で状態を読める（画面には何も出さない）。

## 確認結果（このクラウド環境、ヘッドレス Chromium＋SwiftShader）

詳細は `logs/e04/test.txt`。

- `games/e04/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で実行:
  - 両サイズとも `__ready` = true（約4.5秒）、`__errors` = []、コンソールエラーなし。
  - 24灯・4段階を通ってクライマックスに到達し（SwiftShader で約4分）、フリープレイのハンドル／ランタンのタップまで到達。
  - 画面上の位置: 横 1024x768 では装置の軸 x=512（中央）、目標フック x=512、作業台のランタン x=513。縦 768x1024 では軸 x=384（中央）、最下段の輪の左右端 x=72〜696、太陽形装飾（開いた光条）の上端 y=124、台座 y=637。端で切れていない。
- スクリーンショット: `shot-1.jpg`（序盤）、`shot-2.jpg`（中盤、13灯）、`shot-3.jpg`（クライマックス約14秒、横）、`shot-3-portrait.jpg`（クライマックス、縦）。縦の序盤・中盤（`shot-1-portrait.jpg`, `shot-2-portrait.jpg`）もある。最も光った瞬間でも、群青の空と雲、太陽形装飾の光条と内部構造、ランタンの色、真鍮の輪郭が見えていて白飛びしていない。
- サムネイル: `site/thumbs/e04.jpg`（640x480, 文字なし）。mid（Bloom・Transmission あり）でクライマックスを撮影。同じ実行でもクライマックスとフリープレイまで到達し、エラーなし（`test.txt` の最終行）。
- 禁止語の grep: 該当なし（コード・コメント・このメモ）。
- 共通スクリプト `gf-playlog.js` が外部ホストへ送信しようとするが、このサンドボックスは外へ出られないため、テストではそのホストだけローカルで 204 を返した（ゲーム本体の素材取得ではない）。ゲーム本体の外部リクエストはなし。
- 途中で見つけて直した不具合: (1) ランタンの揺れのばね計算が、フレーム時間が長いと発散して NaN になっていた（細かく分けて計算し、値の保護を追加）。(2) フレームが遅いと「最後の移動と指を離す」が同じフレームに入り、フックの近くでも取り付けにならないことがあった（離したときに最後の指の位置で判定し直すよう修正）。

## 未解決・未検証の点

- iPad / iPhone の実機、Safari での動作・FPS は未検証（GPU のないソフトウェア描画のみ）。画質の自動切替は実装済みだが、実機での切り替わり方は未確認。
- 音はヘッドレスでは鳴らせないため、聴いての確認はしていない（エラーが出ないことのみ確認）。
- 1024x1366 / 1366x1024 / 390x844 は構図計算上は収まる設計だが、スクリーンショットでは未確認。
- 水面は全画質で解析的な反射（High の縮小解像度の実反射は入れていない）。
- 遠景の木は単純な形で、近くで見るとやや作り物っぽい。ランタンは画面上でやや小さめ（装置全体を収める構図を優先）。
- low では Bloom がないため、太陽形装飾とランタンの輝きは加算スプライトで補っている。
