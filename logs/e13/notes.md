# E13 そらいっぱいの シルクのドーム — 実装メモ

実装: `site/games/e13/index.html`（HTML + CSS + JS を1ファイル。Three.js 同梱版を importmap で読み込み。CDN・外部画像・外部モデル・音声ファイルなし。テクスチャ・音はすべてプログラム生成）

## 実装の要点

- **舞台**: 直径約34mの白い石灰岩の円形中庭（石畳は canvas で石ごとの色差・目地・凹凸の法線を生成）。回廊の柱24本・屋根骨組みを支える細い柱12本（柱頭・台座・縦溝の法線、InstancedMesh）、回廊の梁と屋根、植え込み8か所（葉の InstancedMesh を頂点シェーダーで風に揺らす、花）、浅い水盤4か所（法線のゆらぎ＋Fresnel＋空色）。空はグラデーション＋ノイズ雲のシェーダー。環境反射は空と地面の簡易シーンを PMREM で処理（時間帯が変わったときだけ更新）。
- **屋根骨組み**: 外周リング（直径約18m・高さ17.5m）、中央の円形接続部（高さ約22m）、ドームの曲線に沿った真鍮の放射状の梁24本、白い金属の補助ロッド、巻取り装置24個（巻いた絹＋真鍮の芯とキャップ）、中央の真鍮の留め具24個（開閉する爪つき）。
- **絹（主役）**: 24枚（真珠色・桃色・水色・金色を6枚ずつ、隣り合う色が違う並び）。MeshPhysicalMaterial（sheen 0.8・roughness 0.4・clearcoat 0.05・手続き生成の平織り法線マップ normalScale 0.18）を onBeforeCompile で拡張。
  - 形と動きはすべて頂点シェーダー（CPU で頂点を毎フレーム更新しない）: 展開量・垂れ下がり（未固定時）・自重のたわみ（約27cm）・大きな風の波（0.42Hz）・細かな波（1.1Hz）・縁の揺れ・縦のひだ・展開中の進行波・固定時の張力の波・クライマックスの中央から外周への大波・タッチの波紋。隣の布へ位相をずらして波が伝わる。法線は形の関数の差分から計算。
  - 透過光は「布の向こうから太陽が当たっている面」に、染めの色を濃くした色の光を足す近似（前方散乱で強まる、ひだで濃淡）。透明描画は使わない。
  - 床・柱・壁・植物のシェーダーで、各点から太陽方向へドームとの交点を求め、取り付け済みの布の色で直射光を染める（布の形の色の光が中庭に落ちる。クライマックスで一時的に強く）。
- **遊び（指1本）**: 起動直後から中庭と骨組み。最初の布の端が巻物から垂れて風に揺れ、金色の光が縁を伝う。布の端に触れて中央方向へ少し引く（画面短辺の10%で確定、方向は厳密に判定しない）と、巻物が回転しながら約8mの布が勢いよく伸び（約1.5秒、段階で 1.15倍・1.3倍速、最後の1枚は1.5倍長い）、留め具が閉じ、張力の波・金属音・成功音・金色の光粒・縁を走る光。短いタップや途中で指を離しても必ず取り付く。関係ない場所に触れても何も起きない。2.5秒放置で布の端が持ち上がり光が動き、5秒で端と留め具が順に光る。
  - 8枚ずつ3段階（約3区画おき）。第1段階の後は完成した布を光が巡り、第2段階の後は風の波が布から布へ伝わる。段階ごとに空と太陽が午前 → 午後 → 金色の陽光へ。第3段階では残りの巻物がかすかに光り、空いた区画に光粒が舞う。
  - **クライマックス（約12.5秒）**: 中央に金色の光が集まる → 留め具が一斉に光る → 中央から外周へ大きな風の波 → 色ごとに順に反射光が連鎖 → 中庭に色の光が広がる → 光粒と和音 → 風が静まる。続いて余韻10秒 → フリープレイ（布に触れるとその場所から波紋が広がり隣の布へ伝わる、色ごとの音）。余韻後、ドームの梁から小さな絹の巻物が紐で下りてきて、触れると布が巻き戻って最初から遊べる（屋根を勝手に消すことはしない）。
- **白飛び対策（前回の反省）**: ACESFilmic。three の ACES は内部で露出を 1/0.6 倍するため基準露出は 0.80（最大 ×1.07）。ブルームは しきい値1.0＋ソフトニー（0.9）、入力を 2.2 でクランプ（小さな鏡面の輝点が画面全体に広がるのを防止）、強さは通常0.3・成功0.6・クライマックス最大0.82（mid は ×0.85、low はなし）。開発中に「接線なしの anisotropy が HDR 1000 超の輝点を生み、ブルームで画面全体が白くなる」ことを実測で見つけたため anisotropy は使っていない。クライマックスのスクリーンショットで布の色の違い・梁・空の青が見えることを確認。
- **カメラ**: ロールなし・急な動きなし（1.1〜1.8秒の補間）。待機中は布の端・留め具・巻物の両端を投影し、布の端が画面中央付近（NDC ±0.32以内）、他が上下左右8%の余白内に収まる注視点と FOV を数値探索（縦横どちらも同じ仕組み）。展開中は布全体と中央を収める。段階の切り替え・クライマックス・フリープレイは中央の接続部を真上に見上げ、ドーム外周が余白内に収まる FOV（横で約70°、縦で約86°）。ドラッグ中はカメラ固定。
- **入力**: Pointer Events、最初の pointerId のみ（2本目以降は無視）、setPointerCapture、当たり判定は布の端の見た目より広く最低72px。pointercancel・回転・blur・タブ非表示で安全に解除。touch-action・選択・長押し・ダブルタップ・ピンチ・スクロールを抑止。
- **音**: WebAudio のみ。最初のタップで AudioContext 作成・再開（失敗しても進行）。コンプレッサー＋マスター0.32＋合成リバーブ。触れる音、絹の擦れ（ドラッグ速度に連動）、巻物の回転音、展開の風音、留め具の金属音、段階ごとの成功音（単音 → 和音 → 和音＋高音）、クライマックスのアルペジオと Cadd9 系の和音、風の環境音。C メジャー・ペンタトニック。
- **画質**: `?q=low|mid|high` で固定（自動調整停止）。指定なしは mid から開始し、48fps 未満が2秒で1段階下げ、57fps 以上が8秒で上げる（切り替え後10〜20秒待機）。high: PR上限1.75・影2048・ブルーム・布40×16/24×12・光粒240、mid: 1.25・1024・低解像度ブルーム・28×12/18×8・120、low: 1.0・影なし（骨組みの影を床シェーダーで近似）・ブルームなし・20×8/14×6・48。
- **状態**: READY / WAITING / DRAGGING / UNFOLDING / ATTACHING / STAGE_CELEBRATION / CLIMAX / FREE_PLAY / RESETTING。布ごとに rolled / ready / unfolding / fixed。`window.__ready`、`window.__errors`、`window.__test`（state, stage, attached, fps, q, centerNdc, inFrame, climax, peak, afterglow, free, freeTouches など）、`window.__e13`。
- `?autotest`: 通常の pointerdown / move / up を合成して24枚を取り付け（ドラッグ・タップ・短いドラッグ・斜めのドラッグを順に。途中で関係ない場所のタップ1回と2本目の指1回）→ 段階演出2回 → クライマックス → 余韻 → フリープレイで3回タッチ → `finished`。
- 確認用に `?pre=N`（N枚取り付け済みから開始。24ならクライマックスから、`&ct=秒` で途中から）、`?nobloom`、`?nomsaa`、`?dbg` を用意（autotest では pre は無効）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright ヘッドレス Chromium（`--use-angle=swiftshader --enable-unsafe-swiftshader`）で `games/e13/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で全工程実行。結果は `logs/e13/test.txt`、スクリプトは `logs/e13/run-test.js`。
- **横・縦とも PASS**: `__ready === true`、`__errors` 空、コンソールエラーなし、24/24 取り付け → 段階演出2回 → クライマックス（ピーク到達）→ 余韻 → フリープレイ（タッチ3回）→ finished。待機中の布の端の位置は画面中心から NDC 最大 0.35（中央50%以内）、重要な点が画面外に出たフレーム 0、ブルーム最大 0.82・露出最大 0.86。合成の2本目の指を無視1回・関係ない場所のタップ1回も記録。所要 横・縦とも約280秒（約7fps）。
- 最終調整後に `q=low/mid/high` で最初の数枚までの短縮確認（PASS）、縦 768x1024 で完成後の小さな巻物に触れて最初からに戻ること（READY・取り付け0・エラーなし）を確認（test.txt 末尾）。
- スクリーンショット: `shot-1.jpg`（序盤・待機）、`shot-2.jpg`（中盤・12枚後の展開中）、`shot-3.jpg`（クライマックス約6秒＝光のピーク）、`p-shot-1〜3.jpg`（縦）。すべて 300KB 以下の JPEG。クライマックスでも布の色の違い・骨組み・空の青が見え、ドームは縦横とも画面中央に収まっている。
- サムネイル: `site/thumbs/e13.jpg`（high 画質のクライマックス約7秒、640x480、約31KB、文字なし）。
- 禁止語（ひらがな・カタカナ表記を含む）が `site/games/e13/` と `logs/e13/` にないことを grep で確認。

## 未解決・注意点

- iPad Safari 実機での動作・FPS・タッチの感触・音は未確認（SwiftShader は CPU 描画のため性能の指標にならない。自動テストでは発音そのものは検証していない）。
- 自動テストのスクリーンショットは low 画質（ブルーム・影なし）。サムネイルは high 画質。
- 390x844・1366x1024・1024x1366 は全工程の自動テスト未実行（構図は同じ数値探索）。
- 指示文との差: 基準露出 0.80（three の ACES の内部係数を考慮。画面上の露出感は指示文の 1.0 相当を狙った）。ブルームのしきい値は 1.0（ソフトニー付き）。再開用の小さな巻物は、真上を見上げる完成時の視点でも画面内に入るよう、床ではなくドームの梁から紐で下ろしている。展開中の布は物理シミュレーションではなく手続き的な変形。
- 中庭の石畳は見上げる構図のためほとんど画面に映らない（色の光は柱・回廊にも落ちる）。
